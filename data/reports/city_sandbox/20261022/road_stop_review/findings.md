# EXP27 도로·차량·정류장 재점검

사용자가 정류장 위치, 차도·도로, 자동차를 다시 점검해 달라고 요청하여 현재 원천 도형과 실제 엔진 이동을 함께 확인했다. 실제 서울 정류장·차선의 현장 측량이나 현재 운영 정보를 확보한 감사는 아니다. 소방·경찰 시설과 긴급차 음향은 별도 담당 결과에 연결한다.

## 발견과 수정

기존 4개 셸터의 대기 위치는 원본 보행 면에 있고, 전체 셸터·정차 버스는 원본/게임 횡단부를 비운다. 그러나 이 사실만으로 문 앞 접근이 명확하다는 판정은 할 수 없다. 원래 대기점에서 버스 앞문까지 거리는 6.48~9.25m였다. `door_to_wait_m`이라는 예전 JSON 필드도 실제로는 버스 중심선으로부터의 옆 거리다. 이 필드를 실제 문 접근거리라고 사용하지 않는다.

처음에는 다른 차선을 건너야 하는 문제인지 의심했다. 독립 도형 검사 결과 실제 앞문 연결의 차도 구간은 0~0.70m이며 칠해진 차선을 가로지르는 경우는 없었다. 여러 차선 횡단이라는 가설은 기각한다. 긴 보행 연결과 문 위치 안내가 부족한 문제였다.

4번 시청 남측 정류장은 별도의 문제도 있었다. 앞문 쪽 승차 후보의 전체 반경 0.42m 보행 연결이 옆 차도와 약 0.80㎡ 겹친다. 같은 버스의 가운데 문 쪽 연결은 차도·차선·사유지·건물·원본/게임 횡단부를 비운다. 기존의 셸터/버스 사각형 충돌 검사에는 승객의 문 접근 도형이 없어서 이 문제를 검출하지 못했다.

원본 셸터·원본 보행 대기점과 3대의 실제 순환 경로를 유지하면서 다음을 수정했다.

- 실제 문 옆에 별도 승차 표시를 만들고, 대기점에서 짧고 띄엄띄엄 배치한 보행 표식과 실제 거리를 안내한다. 표시 전체는 기존 TIN에 맞추며 새 충돌 바닥을 만들지 않는다.
- 승차 후보를 두 문 모두 검사한다. 원본 차도 전체·사유지·정문 여유를 제외하고, 0.20m마다 실제 캡슐·지면 지지를 확인한다. 4번은 가운데 문으로 안내하고 안전하지 않은 앞문 E 승차도 제외한다.
- 자유탐험 메뉴 바로가기는 실제 승차 표시 옆으로 연결한다. 보행 제한 모드에서는 원래 원본 보행 대기점을 유지하여 이동 권한을 넓히지 않는다.
- 하차는 문 옆 승차 표시에서 이뤄진다. 다른 대안 위치로 밀릴 때도 같은 차도·사유지·정문 제외 검사와 현재 점유 검사를 통과해야 한다.
- E 대상 선택, 도착 대기, 실제 감속·정차와 문 애니메이션, 승하차 후 원래 캡슐/조작 복원을 유지한다. 움직이는 버스에 새 승차 권한을 주지 않는다.

좌표는 게임 원본 지역 XZ 미터다. 공식 정류장 좌표가 아니다.

| 정류장 | 유지한 원본 대기점 XZ | 실제 승차점 XZ | 안내 문 | 보행 연결 |
|---|---|---|---|---:|
| GAME-L01 숭례문 북측 | -3.030, 371.412 | -7.394, 366.111 | 앞문 | 6.87m |
| GAME-L02 북창동 | 24.547, 282.036 | 20.864, 277.885 | 앞문 | 5.55m |

| GAME-L04 시청 남측 | 72.252, 137.370 | 64.747, 135.565 | 가운데 문 | 7.72m |

## 도로와 원래 자동차

독립 도로 표시 검사 8/8에서 기존 보도 표시가 차도/차선을 덮는 겹침 약 6,634.13㎡가 제거된 상태를 확인했다. 원본 차도 밖 보행 도형, 비대칭 남측 도로의 공유 이중 황색 중앙선, 버스 회전부/횡단부의 선 비우기, 원래 자동차 노선과 흰 경계선의 분리를 확인했다. 원본 지형·도로 도형이나 자동차 경로는 수정하지 않았다.

별도 독립 배치 검사 5/5는 4개 정류장의 전체 보행 연결과 6개 원래 자동차 노선 종류를 검사한다. 2,895개 표본에서 전체 승용차 사각형이 원본 차도 안에 있으며 원본 진행 방향을 따르고 흰 차선 경계와 겹치지 않는다. 42개 도로 표시 회랑, 1,044개 칠 도형, 7개 게임 신호 구역을 현재 자료에서 확인했다. 기존 입체 연석은 중앙부 16개 구간이며 전체 도시의 인도 높이를 복원한 결과는 아니다.

실제 엔진 개발 여정 `access_headless_dev02.json`은 27/27을 통과했다. 버스나 자동차·사람 위치/시계를 시험에서 대입하지 않았다. 버스가 자연 정차한 후 버스만 잠시 멈춰 각 원본 대기점에서 W로 실제 걸어가고, 첫 물리 E 입력으로 탑승·하차했다. 원래 14대 자동차와 사람은 계속 운행했다. 14대 모두 68.01~577.57m 실제 주행, 총 18회 현재 틱의 허용 가드를 통한 끝점 재순환, 최대 물리 한 틱 이동 0.16680m·최대 원본 경로 이탈 0.000321m를 관측했다. 이 차량은 원본의 유한한 단방향 노선을 운행하고 카메라/사람/공간 가드를 통과한 끝점에서 재순환한다. 도시 전체 목적지 경로 탐색이 추가된 것은 아니다.

## 증거와 현재 판정 범위

- [기존 도로 표시의 현재 도형](road_plan_before.json): 8/8. 이후 도로 자산·원본 형상·버스 JSON은 변경하지 않았다.
- [전체 차도/보행 연결 독립 감사](placement_final02.json): 현재 소스 SHA, 후보 문별 전폭 도형, 차도 겹침, 원래 차량 노선 표본을 보존한다.
- [첫 실제 보행 개발 실행](access_headless_dev01.json): 25/25.
- [14대 정상 교통을 추가한 개발 실행](access_headless_dev02.json): 27/27. 실행 종료 0, 스크립트 오류 0.
- [구현/증거 인수](component_summary.json): 최종 입력과 부모 에이전트의 native 재검증 필요를 구분한다.

개발 실행 뒤 하차 대안 위치의 원본 차도 제외, 보행 제한 모드 메뉴의 원본 대기점 유지, 4번의 안전하지 않은 앞문 E 제외를 더했다. 따라서 위 개발 수치를 최종 코드의 native 수용으로 재사용하지 않는다. 최종 `bus_access`는 headless 27개 또는 native 31개(네 정류장 실제 화면 포함), 기존 `bus_safety`는 18개를 부모 에이전트가 동결 입력에서 새로 실행한다. native 이미지 저장과 실제 눈으로 본 검수, 엔진 물리 입력과 일반 OS 조작은 별도다.

이 네 정류장은 게임 T01의 남측 순환 동측 구간에 있으며, 서울의 모든 버스 정류장이나 실제 공식 배치를 주장하지 않는다. 차선 폭 3.2m·46초 신호 주기는 게임 정책이다. 모든 도로의 실제 연석·신호 위치나 운영시간을 현장 복원했다는 결론은 내리지 않는다.
