2026-10-13 · 현재 M1 Pro에서 **완료** · [환경/재현 방법](../../docs/environment.md)

## 실제 수행

깨끗한 main의 G04 커밋 `74feb5eaaf118b334e1cf2903a463b44fd08742a`에서 원격 최신을 확인했다. 설치된 Godot이 없는 상태에서 공식 macOS 안정판 4.7.2 Standard를 내려받아 공급자 체크섬·서명·공증을 확인하고 `/Applications/Godot.app`에 설치했다. 지도 원본은 다시 받지 않았다.

빈 Node3D에 카메라·바닥·회전 상자·조명·그림자·닫기 버튼을 실행 때 추가하는 [독립 장면](../../tests/engine_smoke/startup.gd)을 만들었다. 실제 3D 편집기와 macOS GPU 창을 열고 세 렌더러를 순서대로 관찰했다. 테스트는 headless가 아니다.

각 runtime 기록의 viewport는 960×600이고 PNG 저장 오류는 0이다. 실제 기동 로그의 API는 Metal 4.0 및 OpenGL API 4.1 Metal - 91.7이었다. 짧은 시험에서 엔진/스크립트/셰이더 오류는 발견되지 않았다. 자동 fallback 없이 요청한 renderer/driver와 실제 기록이 같았다.

처리 프레임 수와 시간은 장면 루프가 진행됐다는 증거다. 시작 대기시간·CPU/GPU 프레임 시간·평균/p95/p99·도시 부하를 측정하지 않았으므로 성능 순위를 만들거나 30/60fps 목표 달성을 주장하지 않는다. 렌더러별 색/톤 차이도 장소 표현의 확정 스타일이 아니다.

## 선택과 준비 범위

**Godot 4.7.2 / Forward+ / Metal**을 현재 개발 기준으로 고정했다. 공식 안정판이고 기본 렌더러가 실제 편집기·실행창에서 정상 작동해 대체할 기동 문제가 없었다. Mobile/Compatibility는 비교 성공 후보로 남긴다. 이후 도시 성능 문제가 있으면 같은 실제 지도 조건으로 다시 비교한다.

내보내기 템플릿은 미설치다. 편집기/로컬 장면 실행에는 필요하지 않으며, 전체 플랫폼 템플릿은 현재 작업에 사용하지 않는다. 패키지 단계 R03 전에 엔진과 일치하는 4.7.2.stable 템플릿을 준비하고 실제 내보내기를 검증한다. 현재 결과는 배포 앱/서명/내보내기 성공이 아니다.

## 실패와 해결

- 최초 일반 환경의 `sysctl` 조회는 권한 오류가 났다. 허용된 읽기 전용 hardware 조회로 CPU·RAM을 확인했고 기기 식별번호는 수집하지 않았다.
- 웹 읽기 도구의 공식 macOS 다운로드 열람은 timeout/바이너리 redirect 미지원이었다. 공식 아카이브에서 확인한 동일 버튼 URL을 다운로드 도구로 받아 HTTP 200·완료 크기·공급자 SHA-512를 대조했다. 미완료 파일을 검사한 중간 SHA 값은 최종 판정으로 사용하지 않았다.
- 앱 확인 도구가 초기 프로젝트 매니저를 선택해 3D 편집기를 보지 못했다. 빈 매니저를 종료한 뒤 편집기 창을 다시 선택해 실제 화면을 확인했다. 엔진 렌더링 결함이 아니었다. 이후 각 실행창도 별도로 선택했다.
- 종료 후 창 핸들 오류, 활성 상태 갱신 요청은 최신 창 상태를 다시 읽어 해결했다. 보안 설정 변경이나 재설치는 하지 않았다.

## 검증과 인수

[E01 인수 검사](e01_verification.json)는 설치/세 runtime/이미지/로그/캐시 제외/작은 별도 사본의 실제 GPU 재실행·공유 지도 보존·문서 연결을 검사한다. 독립 Sol 검토에서 실제 GUI 증거, E02 범위, 템플릿 미설치와 M4 미검증의 명시를 점검했다.

## 사용자가 확인하면 도움이 되는 시점

이번 화면은 엔진 표시 확인용이다. 기하 형태나 최종 아트 스타일을 정하는 화면이 아니므로 지금 별도의 방향 승인은 필요하지 않다. 현재 Mac 화면이 비거나 깨져 보이는 경우만 알려주면 재현 조건을 확인한다.

다음에는 **E03/E04의 첫 서울 배치 화면**에서 지역이 익숙하게 읽히는지·도로/건물 비율이 자연스러운지, **P/W의 직접 조작**에서 카메라와 걷는 감각·문 통과가 편한지, **L의 랜드마크 표현**에서 서울/한국의 느낌이 충분한지를 검토하면 효과가 크다. 검토 가능한 화면과 관찰 항목을 준비해 알리며 모든 작업에 확인을 요구하지 않는다.
