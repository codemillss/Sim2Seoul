## 높이 의미와 임시값

원문 `height`는 지붕을 포함한 지면 기준 전체 상단 높이, `min_height`는 하단 높이로 읽고 수직 길이는 두 값의 차이다. 원문 전체 높이에 지붕 높이를 다시 더하지 않는다. 위 의미는 [OSM height](https://wiki.openstreetmap.org/wiki/Key:height), [min_height](https://wiki.openstreetmap.org/wiki/Key:min_height), [building:levels](https://wiki.openstreetmap.org/wiki/Key:building:levels), [Simple 3D Buildings](https://wiki.openstreetmap.org/wiki/Simple_3D_Buildings)에 따른 구현 규칙이며 해당 개별 태그의 정확도를 보장하지 않는다.

숫자·m 단위의 양수 단일 값만 사용한다. 복수값·해석되지 않은 단위·비유한 값은 보류하며 층수 추정으로 조용히 바꾸지 않는다. `min_height`가 없으면 로컬 바닥 오프셋 0을 사용하되 실측 지면이라는 표기를 붙이지 않는다. 하단이 상단 이상이거나 하단 원문을 해석할 수 없으면 생성 보류다. 지하층은 지상 층수에 합산하지 않는다.

## 지면 처리

지면 표고를 확보하지 못했으므로 로컬 공학 기준 `y=0m`을 임시 지지 평면으로 정했다. 실제 해발고도·현장 평탄성·DSM 지표가 아니다. 원점·축·미터 축척은 G01 계약 그대로다.

- 예외 없는 1,391개 도형은 이 임시 기준의 참조 상태다. 접근 허가는 모두 `null`이며 지면 형상 검증은 `false`다.
- 계단·교량·터널·0이 아니거나 해석 불가한 layer·지하·물 관련 예외 132개는 `ground_y_m=null`로 보류한다. 도로선 77·건물 52·부분 2·담장면 1이며 지붕 참조도 포함한다. `layer` 숫자를 미터 고도로 변환하지 않는다.
- 기술적 평면 범위는 보존한 전체 도형 외접 범위+10m: X `-905.688…2943.615`, Z `-577.025…733.456m`다. 관계/웨이의 조사 상자 밖 부분을 보존한 결과이며 플레이 경계·스폰·통행 허용 영역이 아니다.
- 정관헌 주변 sand 관계 `r/10757318`을 현재 소구역 원본에서 별도 조립했다. 원문 전체 외곽·내부 구멍과 로컬 XZ 도형을 보존한 참조이며, 자동 보행면 또는 지면 메시로 사용하지 않는다.

## 정관헌과 상동교회

[수동 생성 결정](../manual/height_review_decisions.json)은 측량 보정 승인과 구분한다. 원본 좌표·태그는 변경하지 않았다. [공식 근거와 접근 수준](g03_official_evidence.json)에 검색 본문·직접 열람·직접 접근 실패를 나눠 기록했다.

**정관헌:** 이름이 있는 `w/381755268`의 339.05㎡ 윤곽이 익명 `w/776767573`의 487.44㎡ 윤곽 안에 있고 중심 차이는 약 0.233m다. 작은 이름 윤곽 하나를 임시 본체로 선택했다. 큰 윤곽은 처마/기단 후보라는 미확정 해석을 남기고 참조로 보존한다. 큰 윤곽은 sand 관계의 inner이므로 주변 면의 구멍도 보존했다. 높이는 둘 다 없으며 6m는 가정이다.

궁능유적본부의 [2024-09-11 자료](https://royal.khs.go.kr/ROYAL/contents/R402000000.do?id=20240911102733381067&schBcid=normal1&schM=view)는 서양식 건물에 전통 요소가 가미됐다고 설명한다. OSM `architecture=joseon`만으로 일반 한옥 외형을 확정하지 않는다. [국가유산포털 역사 등록 기록](https://www.heritage.go.kr/heri/cul/culSelectDetail.do?VdkVgwKey=79%2C00820000%2C11&pageNo=1_1_1_1)의 검색 추출에는 1동 1층·297.1㎡·2008-06-23 해제가 나타났으나 직접 페이지 수신은 실패했다. 현재 등록 상태나 실측 윤곽/높이로 승격하지 않는다.

**상동교회:** 본체 `w/1128365145`는 1,992.29㎡·원문 높이 37.4m, 내부의 작은 `w/1128365153`은 189.22㎡·52.1m이며 노드를 공유한다. 큰 본체 하나를 임시 생성 대상으로 택하고 높은 작은 면은 탑/높은 부분 후보로 보존했다. `min_height`와 명시 부모/부분 관계가 없어 시작 높이를 37.4m로 만들어 넣거나 14.7m 두께를 확정하지 않는다. 상세 부분 전략을 도입할 때 본체 전체 볼륨과의 중첩도 다시 검사한다.

[서울미래유산](https://futureheritage.seoul.go.kr/futureHeritageMeet/futureHeritage/view.do?htNo=205)은 1977년 건물과 지상 9층·지하 2층을 설명한다. [서울 건축물대장 목록](https://openab.seoul.go.kr/build/info.do?pageIndex=2676)의 9층·건축면적 1,796㎡는 보조 근거이며 OSM 폴리곤 면적과 정의가 다르다. 목록 직접 열람은 성공했지만 상세 연결은 실패했다. 두 공식 자료에서도 37.4/52.1m의 독립 확인이나 탑 시작 높이는 얻지 못했다.

## 검증·실패·다음 행동

[높이·지면 검사](height_check.json)의 19개 검사가 통과했다. 원문/규칙/수동 결정/공식 근거 해시, 모든 객체 상태, 상단·하단·수직 길이·근거 표기, 생성 대상, 본체 수평 중복 0쌍, 석조전 명시 부분, 정관헌 전체 주변 면/구멍, 지면 예외·접근 미확정을 확인했다. 상세 부분 메시의 수직 중첩을 검증한 것은 아니다.

[회귀 검사](g03_regression_check.json)는 지붕 재합산·없는 바닥 높이 생성·실측 표기 변조·겹침 결정 삭제·주변 면 외곽 이동/구멍 채움·예외 평탄화·해발 기준 조작·작은 부분의 독립 생성·층수 단위 오용·다중 높이 선택·통행 허가 오용 12가지를 필요한 검사에서 모두 거부했다.

최초 검사에서는 높이를 사용하지 않는 토지 면의 `min_height` 비교 오류가 있어 [실패 결과](g03_before_review.json)를 보존하고 수정했다. [독립 Sol 검토](g03_independent_review.json)가 발견한 바닥/주변 외곽/결정 기록/근거 상태 검사 누락 4개도 보강했고, 동일 변형을 해당 검사에서 거부하는 것을 재확인했다. 변경된 정책/큐 때문에 G02 출처 해시를 재생성했으며, 이전 공유 G02 검사는 [스냅샷](geometry_check-g02.json)으로 보존했다.
