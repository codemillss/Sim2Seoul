# N04 최초 실행 보존

- `smoke01`: 최초 GDScript 타입 추론 오류의 로그와 실패 판정. 게임 실행 성공 자료가 아니다.
- `smoke02`: 타입 수정 뒤 짧은 진단 실행. 당시 중간 코드/관측 형식이며 최종 전체 계약을 대신하지 않는다.
- `full01`: 전체 물리 독립 검사는 통과했지만 실행 중 검사기 파일이 바뀌어 `proof_unchanged`가 실패한 최초 전체 실행. 최종 코드가 고정된 실행으로 설명하지 않는다.

최종 headless/실제 GPU 증거는 상위 폴더에 별도로 보존한다. 원시 자료와 원래 실패 판정은 덮어쓰지 않는다. 중간 소스 전체를 복원했다고 주장하지 않으며, 최종 동결 코드와의 구분을 유지한다.
