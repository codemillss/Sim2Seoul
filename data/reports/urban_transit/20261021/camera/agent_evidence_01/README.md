# 교통수단 화면 흔들림: 원시 증거와 소스 동결

- **전체 headless `final06`: 65/65 PASS.** 실제 자전거·킥보드·자동차·열차·버스 이동, 84m/s 헬기, 실제 R 하강/회수 및 메뉴·복귀를 검사했습니다. 모든 이동 구간 카메라 순간 snap은 0이었습니다.
- 최종 `final07` harness는 자연 정차 관찰 180초/전체 420초 예산만 확장했습니다. 생산 파일은 그대로이고 parser PASS입니다. 정확한 최종 SHA는 `source_freezes/freeze07.json`입니다. 이 최종 harness 전체 native 검사는 root의 원래 `../../acceptance/camera_native_final02.*`에 별도로 기록됩니다.
- `development/`에는 수정 전 5개 표시 오차 실패, 잘못된 헬기 초기 위치, 버스 다른 차량 context/특정 차량 관찰 예산 실패를 그대로 보존했습니다. 실패를 제외해 전체 PASS로 다시 쓰지 않았습니다.
- `source_freezes/`에는 수정 전 및 단계별 소스를 보존했습니다. 로프의 마지막 변경은 아바타·하네스·줄 양 끝의 표시 시각과 항공기 render callback 순서뿐입니다. 원본 물리/바닥/충돌/경로/속도/로프 이동·목적지는 변경하지 않았습니다.

`summary.json`은 결과·정확한 범위·시간선입니다. `manifest.json`은 원래 파일 경로, SHA-256, 크기, 압축 여부 및 바이트 왕복 검증입니다. 원시 JSON/로그 본문은 바꾸지 않았고 긴 로그만 무손실 gzip으로 저장했습니다. 원시 내부 `/tmp` 경로는 원래 값을 유지하며 manifest로 저장 위치를 찾습니다. Native 실패의 7개 PNG는 원래 `acceptance/` 경로에 유지합니다.

표시 좌표 오차는 공통 보간 시각을 지키는지의 검사입니다. 프레임률·성능·사람이 느끼는 편안함, 실제 OS 입력의 증명으로 해석하지 않습니다.
