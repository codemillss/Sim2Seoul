# 기존 자산을 수정하는 대안

검토일: 2026-10-15. 사용자의 대안 질문에 대한 첫 조사는 기능/자료 안내 확인이었다. 이후 L03의 “기존 모델을 가져와 수정하는 방법부터 비교” 지시로 **실제 CC0 파일 취득·Godot 가져오기·수정·동일 시점 비교**까지 수행했다. 아래 일반 대안 조사와 실제 실행을 구분한다.

현재도 OSM 실제 도로·건물 배치, Overture 보완 자료와 Godot를 재사용한다. 직접 작성한 부분은 이 입력을 미터 공간에 연결하는 처리·통로/경계와 장소 특징 외형이다. 아래 세 대안을 모두 나란히 실행한 것은 아니며, L03에서는 기존 건물 모델 한 개의 수정 경로를 실제 시험했다.

| 경로 | 줄일 수 있는 일 | 별도로 필요한 일 |
|---|---|---|
| [OSM2World](https://osm2world.org/)로 지도→3D 변환 | 일반 도로·건물·지붕 생성과 glTF/GLB 등의 가져오기 | 궁궐 고유 형태·원점/축척·개구부·보행 충돌. [기존 모델로 건물 교체](https://osm2world.org/blog/2025/09/05/3dmr/)도 지원 |
| 기존 건물·시설 모델 수정 | 외형 모델링, 나무·가로시설 등의 반복 제작 | 개별 파일 이용 조건·출처·폴리곤/재질 비용·방향/크기·통로 정합 |
| [Godot 공식 3인칭 데모](https://github.com/godotengine/tps-demo/blob/master/LICENSE.md) 등에서 시작 | 이동·카메라·메뉴의 초기 뼈대 | 실제 서울 자료 결합·생활 요소·프로젝트 규칙에 맞는 수정. 코드와 그래픽 자산의 이용 조건은 서로 다름 |

[3D 국가유산 서비스](https://www.heritage.go.kr/heri/html/HtmlPage.do?pg=%2FthreeD%2F3dInfomation.jsp)도 후보이나 이번에는 필요한 덕수궁 모델의 실제 파일 확보, 개별 게임 이용/수정/재배포 조건, Godot 가져오기·경량화를 확인하지 않았다. 무료로 볼 수 있다는 사실을 파일 전체의 재사용 허가로 바꾸지 않는다.

L02 종료 당시에는 파일을 수입하지 않고 한 자산 비교를 권고했다. 현재 L03은 그 비교를 수행한 아래 결과를 사용한다. 기존 외형 층만 교체하므로 좌표·이동·충돌을 다시 만들 필요는 없었다.

## L03 실제 비교와 선택

| 후보/방법 | 실제 확인·실행 | 선택과 비용 |
|---|---|---|
| [Kenney City Kit Commercial 2.1](https://kenney.nl/assets/city-kit-commercial) | 공식 ZIP 4,096,974B·동봉 CC0 확인. GLB 111,336B+상대 PNG 11,002B를 실제 native import. 원본1재질/1,292삼각형 | 주변 빌딩1곳에 한정해 수정 사용. 실제 SFC 모델이 아니며 비균일 확대 후 창 구획이 과장돼 색/외곽 절삭/층 분할을 추가 |
| 정확한 서울시청 후보 [3D Warehouse](https://3dwarehouse.sketchup.com/model/54c89b3e26b41f7d8a87581552df362b/Seoul-City-Hall) | 검색 후보 확인, 상세 접근403·실물 파일/수정·저장소 재배포 조건 미확보 | 수입하지 않음. 시청/도서관은 고유 실루엣을 직접 단순화 |
| OSM2World 0.4.0 | 공식 기능/Java17·배포 ZIP 약431MiB 확인 | 이번 작은 비교에서는 다운로드/설치/실행하지 않음. 이미 검증한 지도/문/보행을 대체할 이득을 증명하지 않음 |
| 기존 단순 부피 유지 | 현재 SFC 44삼각형과 같은 시점 비교 | 가장 가볍지만 유리/석재 입면 특징 부족. 롤백 가능한 원본으로 보존 |

최종 SFC 표시5부품/6,600삼각형에는 수정한 원모델2,024삼각형·새 석재 저층부·얇은28분할이 포함된다. 원본보다 비용은 늘었고 무조건 더 빠른 제작 방식이라는 결론은 내리지 않았다. 전체 L03은4대상/18부품/10,024삼각형이다. native import+정점/재질 추출은 최초 단일 관측11,561µs였지만 장면 로딩·수정 노동·GPU 성능 벤치마크가 아니다. 수작업 총 시간은 계측하지 않았고, 실제 수정/실패 이력으로 부담을 기록했다.

실제 화면에서 원모델의 밝은 색과 큰 창 구획, 시청의 처음 평평한 상자 인상을 확인한 뒤 수정했다. **배경 건물은 CC0 수정 모델, 시청/도서관은 독립 단순화, 광장은 원본 외곽 유지**로 범위를 정했다. 재사용은 주변 반복 자산부터 늘리고 핵심 장소는 정확한 모델·조건·정합이 확보될 때 다시 비교한다. [원본/수정본·최종 화면·검사와 실패](../data/reports/city_landmarks.md), [파일별 출처](ATTRIBUTION.md), [판단 원천](../data/manual/l03_city_decisions.json).

현재 결과와 다음 작업은 [WORK_STATUS](WORK_STATUS.md)가 기준이다. 자산을 가져오기 전에는 파일별 출처·조건과 공유 범위를 [ATTRIBUTION](ATTRIBUTION.md)에 추가한다.
