# 도시 액션과 차량 상호작용

2026-10-23 EXP32 개발판. [현재 실행·소스·원시 기록](../data/reports/city_action_freedom/20261023/summary.json)을 기준으로 한다. GTA의 자유로운 도시 이동/행동을 참고한 독립 게임 구현이며 상용 게임 자산이나 코드를 추출하지 않았다.

## 조작

| 행동 | 방법 |
|---|---|
| 연속 타격 | F를 동작이 끝날 때마다 새로 눌러 왼 잽→오른 스트레이트→왼 훅. 잠깐 쉬면 잽부터 시작 |
| 밀기 모션 | X. 양팔을 펴고 명중한 인물은 조금 더 오래 움찔 |
| 방어 자세 | G를 누르고 유지, 놓으면 중립 복귀. 다른 공격은 G를 놓고 입력 |
| 도로 차 정차 요청 | 원래 움직이는 차 가까이 E, 실제로 문 바로 옆까지 WASD 접근 |
| 차량 진입/취소 | 운전자 반응→짧은 문 잡기/진입 동작→운전. 도중 E로 취소 |
| 운전/경적 | W 가속, S 제동/후진, A/D 조향, Space 브레이크, H 경적, E 정차 후 하차 |

Esc의 **도시 액션 · 도로 자동차 가까이 가기**를 사용한다. 이전 속도/시간 선호는 유지하며 움직임을 자세히 보고 싶으면 **자연스러운 걷기·달리기 체험**을 선택한다. 새 기능은 이전에 열어둔 창에 자동 반영되지 않으므로 새 실행이 필요하다.

## 바뀐 흐름

기존 F의 한 동작·즉시 판정을 세 동작과 준비/접촉/회복으로 나눴다. 접촉 때 상대가 떠났거나 벽이 끼면 빗나가고, 성인에게 명중하면 원래 게임 경찰 신고와60초 추격·조사/유치가 이어진다. 반복 키 유지나 키보드 echo가 자동으로 연속 명중을 만들지 않는다. 체포나 탑승 뒤 남은 주먹 동작이 다시 재생되지 않도록 소유권을 정리했다.

도로 차는 원래14개 body/모델/충돌/경로를 그대로 사용한다. 멀리서 운전석으로 바로 옮기던 흐름에 문 접근과 운전자 반응/탑승 시간을 넣었다. 검증한 외부 캡슐 위치에 별도 인체 운전자가 나타나 짧게 걸어 비키며 최대4명으로 제한한다. 원래 NPC28명/개2마리와 별개다. 성공한 차만 AI/FIFO에서 인계하고 취소는 현재 교통 설정에 맞게 되돌린다. 경적은 직접 합성한384/512Hz 음이며 차량 음량/음소거를 따른다.

## 실제 확인과 남은 표현

일반 장면의 물리 입력 검사와 별도 승하차 손/카메라 검사, 원래 차량14대·경찰 추격/구금·생활 활동·보행 회귀를 함께 기록한다. 실제 W 접근, source/native 관절 방향과 손 이동, native 이미지·일반 OS 창은 서로 다른 증거다. 실행별 수와 현재 소스 해시는 집계를 따른다.

주먹의 손가락은 아직 원래의 펼친 형상이고, G는 방어 자세다. 공격 판정은 인물 중심의 게임 거리/방향/시선이며 손가락 충돌·신체 밀림·체력/피해량 시스템은 없다. X도 모션과 움찔 반응이다. 운전자는 차량 안에서 끌려 나오는 연속 메시가 아니라 검증한 바깥 위치에 추가한 배우이며, 원래 일체형 차문은 실제로 열리지 않는다. 짧은 손잡이 표시와 상체 진입 동작을 완전한 좌석 승하차/mocap·GTA 품질로 표현하지 않는다.

현재 지도·한국적 생활 공간은 유지하며 실제 서울의 치안/법률/차량 운영을 재현한 규칙은 아니다. 장시간 FPS·다른 Mac/export·사용자 편안함은 별도로 확인해야 한다.
