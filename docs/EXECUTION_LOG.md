## 2026-10-12 · 준비: 지도 확보와 상세 계획

- 목적/지시: 첫 보행 버전 제작에 앞서 대체 지도 확보 경로와 세세한 실행 계획을 준비한다. 사용자는 비용을 고려해 Sol로 이어가길 원했다.
- 실제 시도: Overpass 두 서버 조회가 각각 HTTP 504·500으로 실패했다. Geofabrik 날짜 고정 한국 PBF로 경로를 바꿔 288,878,500 bytes를 받았다. 기준 시각은 2026-10-09T20:21:04Z이며 모든 객체의 현장 갱신일을 뜻하지 않는다.
- 입력/출력: 국가 원본에서 조사 bbox의 참조를 보완한 지역 v1을 만들고, 자료 도구·설정·출처·계획 문서를 작성했다. 국가 원본은 로컬 전용, v1은 187,286 bytes다.
- 검증/증거: 공급자 MD5 일치, SHA-256, 기본 참조·도형 검사를 기록했다. [조회 실패 기록](../data/availability_check.json), [출처 manifest](../data/reports/source_manifest.json), [v1 추출 manifest](../data/reports/extract_manifest-v1.json), [v1 감사](../data/reports/osm_audit-v1.json), [준비 검사](../data/reports/preparation_checks.json).
- 계획 보완: P01의 독립 충돌 시험 장면을 먼저 만들고 실제 도시 동선 검증은 W 단계에서 하도록 선행 순서를 정리했다. 아직 만들지 않은 동선이 조작 시험의 선행 조건이 되는 문제를 피했다.
- 남은 일/당시 다음: 높이·도로폭·지면·실제 보행 연결은 미검증이며 게임은 없었다. 기존 자료를 인수하는 D01부터 진행한다.
