## 2026-10-12 · 준비: 지도 확보와 상세 계획

- 목적/지시: 첫 보행 버전 제작에 앞서 대체 지도 확보 경로와 세세한 실행 계획을 준비한다. 사용자는 비용을 고려해 Sol로 이어가길 원했다.
- 실제 시도: Overpass 두 서버 조회가 각각 HTTP 504·500으로 실패했다. Geofabrik 날짜 고정 한국 PBF로 경로를 바꿔 288,878,500 bytes를 받았다. 기준 시각은 2026-10-09T20:21:04Z이며 모든 객체의 현장 갱신일을 뜻하지 않는다.
- 입력/출력: 국가 원본에서 조사 bbox의 참조를 보완한 지역 v1을 만들고, 자료 도구·설정·출처·계획 문서를 작성했다. 국가 원본은 로컬 전용, v1은 187,286 bytes다.
- 검증/증거: 공급자 MD5 일치, SHA-256, 기본 참조·도형 검사를 기록했다. [조회 실패 기록](../data/availability_check.json), [출처 manifest](../data/reports/source_manifest.json), [v1 추출 manifest](../data/reports/extract_manifest-v1.json), [v1 감사](../data/reports/osm_audit-v1.json), [준비 검사](../data/reports/preparation_checks.json).
- 계획 보완: P01의 독립 충돌 시험 장면을 먼저 만들고 실제 도시 동선 검증은 W 단계에서 하도록 선행 순서를 정리했다. 아직 만들지 않은 동선이 조작 시험의 선행 조건이 되는 문제를 피했다.
- 남은 일/당시 다음: 높이·도로폭·지면·실제 보행 연결은 미검증이며 게임은 없었다. 기존 자료를 인수하는 D01부터 진행한다.

## 2026-10-12 · D03: 보완 지도 자료 취득·분류·검증

- 목적/지시: 보완 지도 자료를 확보하고 실행 내용·검증 결과도 기록해 함께 push하라는 사용자 요청.
- 시작 입력: 공유 커밋 `0922c27288d0e349232a354a7fb71ea853fdfc6a`, OSM v2와 기존 감사·D03 계획. 원본을 다시 다운로드하지 않고 부족한 높이·지형·공식 접근 근거를 조사했다.
- 실제 취득: Overture 2026-09-23.1 지역 건물 GeoJSON 497,524 bytes, Copernicus 공개 타일 29,862,574 bytes 및 지역 참고 사본 5,356 bytes, VWorld 컬럼 정의서 224,314 bytes, 공식 덕수궁 HTML 10개·지도 메타데이터 3개. 출처·시점·해시는 [자료별 상태](../data/reports/supplemental_status.json)와 개별 manifest에 기록했다.
- 막힌 경로/대안: 서울 SHP는 로그인 모달과 RaonK 전송 안내 단계에서 본체 미수신, NGII는 공식 로그인·전송 요구와 지역/Mac 환경 미확인으로 남겼다. 컬럼 정의서의 브라우저 취득이 장시간 반환하지 않아 중단하고 공개 정적 URL의 직접 수신으로 바꿔 성공했다. 인증이나 설치를 우회하지 않았다.
- 도구/변경: `acquire_supplemental.py`, `review_supplemental.py`, 추가 의존성, 선택 파일 Git 규칙·출처 표시를 추가했다. OSM v2는 변경하지 않았다. `prepare_osm.py`의 감사에 미리보기/설정 해시를 추가하고 공유 파일 검사도 보완했다.
- 발견/수정: 최초 검토 도구의 감사 키 참조 오류를 실제 키에 맞췄다. Overture bbox 조회의 범위 밖 3개를 처음 검사에서 발견해 [실패 결과](../data/reports/d03_before_review.json)를 보존하고 사용 후보에서 제외했다. 원본은 그대로 유지했다. 별도 코드 검토에서 미리보기 파일의 출처 연결 누락을 발견해 해시 대조를 추가했다.
- 실제 검증: 현재 M1 Pro에서 17개 보완 검사·공유 파일 해시·의존성 검사 통과. 정의서 ZIP CRC와 A16/A26/A27/A28 정의를 원본 XML에서 확인했다. 조사 지도 SVG를 렌더해 배치·명칭·축척 표기를 확인했다. 상세 [D03 보고서](evidence/D03_SUPPLEMENTAL_REVIEW.md)와 [검사 JSON](../data/reports/d03_supplemental_review.json).
- 공유 범위: 작은 Overture·DSM 사본과 도구·출처·검증·실행 기록을 함께 공유한다. 전체 DSM·국가 지도·정의서 원본·참고 HTML·환경은 로컬에 둔다. 별도 파일 사본에서 원본 없는 재현과 미리보기 변경 감지를 검증하고 그 결과를 아래 기록에 덧붙인다.
- 한계: 실제 교차 733개 중 높이 100개는 OSM 원천으로 독립 높이 보완이 아니다. 추가 윤곽 22개는 후보이며 자동 추가하지 않았다. DSM은 거친 지표 자료로 보행 지면에 사용할 수 없다. 현재 R2 연속 횡단/R3 전체 순환·상세 폭/단차·현장 정확도·게임·M4 기기 검증은 미완료다.
- 범위/계약: 사용자 확정 목표는 유지. 공유 원본의 지정 범위와 미리보기 추적 규칙만 보완했다. 엔진·좌표·게임 수직 기준·건물 실내 범위는 확정하지 않았다.
- 다음: **D04**, 이 보고서와 자료별 상태·공식 경내 근거에서 사용할 원천과 결손/추정/수동 보완을 분리해 `docs/data_gaps.md`를 만든다.

D03 인수 확인: [별도 사본 검사](../data/reports/d03_portability_check.json)에서 공유 대상 파일 58개를 복사해 국가 원본·전체 DSM 없이 미리보기를 재생성하고 15개 지역 검사를 통과했다. 전체 DSM 비교 2개는 미실행이다. 변조한 미리보기/보완 원본이 거부되고 복원 후 공유 파일 내용이 유지됨을 확인했다. 문서 17개·로컬 링크 138개 검사에서 끊어진 링크 0개였으며, 이번 기록에 추가한 검사 보고서 연결도 확인했다. 기존 설치 환경을 쓴 현재 M1 검증으로 M4나 새 설치 성공을 대신하지 않는다.

## 이후 작업을 끝낼 때 추가할 양식

아래를 실제 결과로 채워 새 항목으로 추가한다. 수행하지 않은 검증은 “미실행”으로 남긴다. 완료하지 못한 작업도 시도·현재 입력·막힌 이유·재개 조건을 기록한다. 작업 산출물과 이력·현재 상태를 같은 커밋으로 공유하며, 커밋 번호는 Git 이력으로 찾을 수 있어 본문에 자기 커밋 해시를 미리 넣을 필요가 없다.

```text
날짜 · 작업 ID/제목 · 완료/부분 완료/실패
목적과 변경 근거: 사용자 지시 또는 구현 판단
```
