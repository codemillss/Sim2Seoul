## 왜 이 공간을 만드는가

사용자는 실제 서울을 직접 돌아다닐 수 있는 개인용 공간을 먼저 만들고, 그 위에 생활·꾸미기·주민이나 다른 시뮬레이션을 얹고 싶어 한다. 첫 공간은 실제 도로·건물 배치와 축척을 보존해야 한다. 데이터 준비 자체가 최종 결과는 아니다.

장소를 고를 때 유동 인구만이 아니라 다양한 나이·성별의 사람들이 가봤을 법하고 공감할 만한 곳을 원했다. 이어 한국의 전통적인 느낌과 서울의 느낌이 공존하면서 빌딩도 보이면 좋겠다고 했고, **“덕수궁과 시청주변으로 하자”**고 정했다. 따라서 궁궐만 고립해서 만들거나 실제 위치와 무관한 서울풍 배경으로 바꾸면 의도에서 벗어난다.

**“안에도 들어가야지”**라는 초기 요구는 W0/V0에서 대한문을 통과해 덕수궁 경내를 걷는 것으로 반영됐다. 2026-10-16 EXP03에서는 사용자가 서울도서관 1층 로비를 첫 실내 대상으로 선택했다. EXP04에서 일반 건물 125개의 게임 실내·상층·계단·승강기까지 범위를 넓혔다. 개별 전각의 실제 방·복도 복원이나 실측 실내 도면은 여전히 대상이 아니며, 초기 경내 보행의 완료와 새 건물 방문 검증을 구분한다.

## 사용자 검토 알림

2026-10-13 사용자 지시: 직접 확인·점검·인사이트가 도움이 되는 경우 알려주되 매번 요청하지 않는다. 에이전트가 실행/자료 검증을 수행하고, 사용자 판단이 유용한 배치·축척의 첫 화면(E03/E04), 조작·카메라·동선(P/W), 랜드마크의 장소 인상(L)에는 검토 가능한 결과와 구체적인 관찰 항목을 준비해 알린다. 단순 설치·반복 검사에 별도 방향 승인을 추가하지 않는다. 건물 실내 등의 큰 미정 범위는 구현 직전에 구체화한다.

## 전체 흐름과 완료 의미

**D 자료 → G 좌표·도형 → E 엔진·지도 표시 → P 조작·충돌 → W 보행 → L 장소 표현 → N 도시 움직임 → R 성능·패키지·두 Mac 검수**의 8단계, 32작업으로 진행한다. 세부 선행 조건은 [상세 작업 계획](IMPLEMENTATION_TASKS.md)을 따른다. 작은 독립 장면의 기동 시험 등은 선행 조건이 준비되면 병행할 수 있다.

- **W0:** 실제 배치의 보행 중간 결과. 대한문 밖→경내, 확인한 횡단 연결→서울광장·시청, 확인한 돌담길 구간을 완주하고 축척·캐릭터·카메라·충돌을 검증한다.
- **V0:** W0에 랜드마크 특징·주변 빌딩·보행자·차량·조작 안내·품질 설정·로컬 패키지·기기 검증을 더한 합의 첫 버전이다. W0만으로 V0를 완료 처리하지 않는다.

자료의 참조·도형 검사가 통과해도 실제 서울의 높이·출입 조건·현장 정확도·게임 보행이 검증된 것은 아니다. 원본 값, 추정 값, 수동 보완을 구분한다.

## 결정이 바뀔 때

사용자가 방향을 바꾸면 이 문서의 해당 항목을 갱신하고 실행 이력에 **변경 전후·사용자 지시 또는 구현 근거·영향받는 작업·남은 검증**을 적는다. 좌표나 생성 규칙이 바뀌면 계약·설정·검증도 함께 맞춘다. 이전 결정을 흔적 없이 지우지 않는다.

이 문서는 대화 전체의 복사본이 아니라 이어서 개발하는 데 필요한 합의와 이유다. 확인할 수 없는 과거 발언·날짜·선택지 의미는 추가하지 않는다. 최신 사용자 지시와 문서가 충돌하면 그 지시를 반영하고 영향받는 기록을 함께 갱신한다.

2026-10-13 P03 직접 조작감 확인 요청에 사용자는 “아직 확인하지 못함”으로 답했다. 자동 검사 결과와 직접 확인을 구분하며 다음 실제 대한문 보행 화면에서는 접근·카메라·거리감을 함께 검토할 수 있도록 준비한다.

2026-10-13 W01 확인 요청에 사용자는 “알아서 계속 만들어 당분간은너가해”라고 답했다. 당분간 기존 목표·계획 범위의 구현·검증·기록·Git 공유를 에이전트가 이어간다. 직접 조작감은 미확인으로 유지하며 매 단계의 선택적 확인 질문을 반복하지 않는다. 실내 범위 등 사용자 의도나 작업량을 크게 바꾸는 결정이 필요할 때만 구체적인 결과와 함께 확인한다.

2026-10-16 사용자는 최초 계획이 마무리될 때까지 사용자 검증 없이 에이전트가 스스로 검증하며 진행하라고 지시했다. 기존32작업의 선행 조건·검증·기록/공유를 따라 끝까지 진행하며 단계마다 다음 승인을 요청하지 않는다. 실제 실행·독립 관측·실패 수정으로 검수하고, 직접 사람 조작감이나 접근할 수 없는 M4 시험을 자동 통과로 바꾸지는 않는다. 별도 실내/생활AI·서울 전역 같은 새 목표를 추가한 지시가 아니다.

2026-10-15 사용자는 기존 결과물을 수정하는 방식도 가능한지 질문했다. [재사용 대안 조사](ASSET_REUSE_OPTIONS.md)에 공식 기능·미확인 파일 조건과 실제 비교가 없었던 한계를 기록했다. 이번 질문을 엔진 변경·외부 모델 도입 승인으로 읽지 않는다. 현재 보행 기반을 유지하면서 외형만 대체할 수 있으며, 확대 전에 후보 한 개로 가져오기/수정 비용·화면·성능·사용 조건을 비교하는 것이 권고다.

이에 따라 원래32작업의 기능 구현·자체 검증·개인용 앱·기기별 판정까지 정리했다. 원래 계획 종료 당시에는 y0 지면/추정 높이·실측/접근, 약한3랜드마크, 실내·생활AI를 남은 한계/미정으로 남겼다. 이후 사용자가 요청한 EXP03의 사진 참조 외형과 첫 서울도서관 로비는 별도 후속 작업이며, 원래 계획의 종료를 모든 기기·사람 시험이나 새 실내의 성공으로 설명하지 않는다.
