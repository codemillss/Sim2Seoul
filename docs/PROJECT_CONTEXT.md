# 프로젝트 맥락과 결정

기준일: 2026-10-15. 다른 컴퓨터나 새 에이전트가 같은 목표로 작업하기 위한 결정 요약이다. 현재 진도는 [WORK_STATUS](WORK_STATUS.md), 상세 제작 순서는 [MASTER_PLAN](MASTER_PLAN.md), 변경 과정은 [EXECUTION_LOG](EXECUTION_LOG.md)을 따른다.

## 왜 이 공간을 만드는가

사용자는 실제 서울을 직접 돌아다닐 수 있는 개인용 공간을 먼저 만들고, 그 위에 생활·꾸미기·주민이나 다른 시뮬레이션을 얹고 싶어 한다. 첫 공간은 실제 도로·건물 배치와 축척을 보존해야 한다. 데이터 준비 자체가 최종 결과는 아니다.

장소를 고를 때 유동 인구만이 아니라 다양한 나이·성별의 사람들이 가봤을 법하고 공감할 만한 곳을 원했다. 이어 한국의 전통적인 느낌과 서울의 느낌이 공존하면서 빌딩도 보이면 좋겠다고 했고, **“덕수궁과 시청주변으로 하자”**고 정했다. 따라서 궁궐만 고립해서 만들거나 실제 위치와 무관한 서울풍 배경으로 바꾸면 의도에서 벗어난다.

**“안에도 들어가야지”**라는 요구는 현재 기획에서 대한문을 통과해 덕수궁 경내를 걷는 것으로 반영됐다. 개별 전각·일반 건물의 실내 방과 복도까지 만들지는 아직 정하지 않았다. 이 구분은 이후 범위 논의에서도 유지한다.

## 사용자 방향으로 유지할 사항

아래는 기존 기획에서 합의한 내용을 문장으로 정리한 것이다. 원래 선택지의 A/B/C 문자만으로 다른 의미를 복원하지 않는다.

| 항목 | 유지할 내용 | 판단에 미치는 영향 |
|---|---|---|
| 대상 장소 | 덕수궁 경내·대한문·돌담길·서울광장·시청 주변 | 전통 건축과 현대 빌딩을 함께 경험할 수 있어야 함 |
| 지리와 표현 | 실제 배치·축척, 주요 비례와 형태를 살린 단순화한 3D | 임의 배치로 대체하거나 세부 외형 제작부터 시작하지 않음 |
| 이동 | 사람 크기의 임시 캐릭터, 3인칭 탐험 | 평면 지도 보기만으로 보행 기능을 완료 처리하지 않음 |
| 경내 진입 | 대한문 안쪽의 길·마당·전각 사이를 이동 | 문 개구부와 충돌·연결 동선을 별도 검증 |
| 첫 버전의 움직임 | 정해진 경로의 간단한 보행자·차량 | 도시 분위기 표현이며 실제 교통 예측 모형은 아님 |
| 사용과 확장 | 처음에는 로컬에서 혼자 사용, 이후 생활 요소나 다른 시뮬레이션 | 초기부터 서버·경제·멀티플레이를 필수로 추가하지 않음 |
| 비용과 개발 | 무료 도구·공개 데이터부터, Sol로 개발 지속 | 비싼 모델이나 유료 자료가 필수라고 가정하지 않음 |
| 기기 공유 | 전용 비공개 Git 저장소, 작은 지도와 작업 맥락 공유 | 다른 Mac에서도 동일 입력·계획·증거로 재개 |
