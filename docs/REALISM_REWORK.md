# 덕수궁·시청 권역 현실성 재정비

2026-10-17 · 상태: 기능·시각 검증과 인수 정리 중. 지형 source 확보와 실제 게임 높이 연결을 구분한다. 이전 모듈 존재나 기능 검사만으로 사용자 체감의 완성을 판정하지 않는다.

## 실제 피드백에서 바뀐 판단

- ‘옥상 도착’은 점프/바로가기/승강기 중 어느 경로든 같은 물리 승강장에서 E로 내려갈 수 있어야 한다. 기존 방문 상태에만 묶여 직접 도착 뒤 승강기가 먹통이었던 결함을 고친다.
- 큰 사각 수조를 지붕에 올린 모습은 호텔 야외 풀의 인상을 충족하지 못했다. 데크 자체를 원본 지붕 위에 제한적으로 올리고 수영 부분에 실제 구멍을 내어 수면/계단/라운지를 연결한다. 원본 건물을 뚫거나 실제 호텔 시설이라고 주장하지 않는다.
- 같은4명이 모든 층을 도는 상태는 장소성을 충족하지 못한다. 로비 직원/여행객, 객실층 청소/투숙객, 운동/독서/업무/예배의 다른 복장·소품·자세·자리를 구현한다.
- 객실은 장식 문짝으로 끝내지 않는다. 관리자 마스터키는 기본 ON인 로컬 1인 기능이며 실제 문 충돌·통과·닫기 안전·내부 퇴실을 확인한다. 기존 외부 사유지/보호 구역은 해제하지 않는다.
- 외부 지도에는 롯데호텔이 있지만, 보수적인900×920m 직사각형 경계가 외곽1.8%를 잘라 방문 생성에서 통째로 제외했다. 실제 config bbox의 투영 사각형 안에는 전부 포함된다. 원래125개를 보존하고 별도 추가카탈로그로 롯데 한 동을 병합한다. 롯데백화점은 실제 bbox 밖 부분이 커 배경 외관이며 방문 추가를 확정하지 않는다.
- 가로수 원본354개가 작은 지역 PBF에 있었으나 기존 features 경로에서 추출되지 않았다. source tree를 우선하고 실제 두꺼운 장벽의 world footprint·입구/차선/시야를 검사한다. 누락 구간의 추가 나무는 창작 배치로 분리한다.
- 기존 일부 보행/차량이 존재하더라도 넓은 지역이 비어 보였다. 추가20인/10원본 보행 구간과8대/4원본 도로로 분산하고, 새로운 보행/차량/나무가 기존 출입과 서로를 막지 않는지 검사한다.

## 기능과 시각 수용의 구분

이전 EXP16–19의 headless296/Metal240 검사는 당시 코드의 지정 기능 통과이며, 이후 사용자 피드백에 따라 형태·경로·표시가 바뀌어 최종 증거를 새로 만든다. 초기 보행 재개 검사는 끝점 왕복의 순변위를 오해했고 실제 누적2.4687m 이동/접지/방향 전환으로 확인했다. 최초 GPU 실내 검사는 마지막 덤벨 촬영에서 무기한 render 신호를 기다릴 수 있었으며, 명시적 그리기와 유한 관찰을 연결한 뒤114개를 완료했다. 원인 단정과 성능 합격은 구분한다. 큰 풀 초기 두 탈출 화면은 시야가 수조 벽에 눌려 캐릭터가 사라졌다. 이후 형상 재설계와 실제 기본 카메라/머리 시야 검사를 요구한다.

## 지형: 현재 핵심 미완료

현재 전체 지면은 원래 평면과 게임용 미술관3m 경사다. 사용자 요청은 특정 구간이 아니라 권역 전체의 현실적인 높낮이다. 기존 Copernicus30m DSM은 건물·수목을 포함하는 표면 참고 자료여서 보행 지면으로 적용하지 않는다. 공식 국토정보플랫폼의 서울37608 공개 DEM은 실제 다운로드에 로그인이 필요했고, 사용자는 로그인하지 못해 다른 방법을 요청했다. NEINS 공개 지점은10~50m 같은 분류만 반환해 정확 표고로 쓸 수 없다. 그 다음 서울시 공식 익명 경로를 확보했으며 아래에 실제 결과를 기록했다. [취득 조사/원응답/공식 화면](../data/reports/realism_rework/20261017/terrain_research.json).  수직 기준/지역 원점과 도로·건물 기초·출입구·NPC/차량/회복 위치를 함께 연결해야 한다. 임의로 잔물결만 추가해 실제 지형으로 표시하지 않는다.

## 로그인 없는 실제 지형 원천 확보 (2026-10-18)

사용자는 NGII 로그인 완료 답을 바로 정정해 로그인하지 못했으며 다른 경로를 요청했다. 서울 열린데이터광장의 ‘서울시 경사도’ 항목은 표고점/등고선 source를 제공했고 정식 익명 POST 다운로드로 실제 ZIP을 받았다. [지역 원천 manifest](../data/raw/supplemental/seoul_terrain/20261018/manifest.json): 정확한 config bbox+200m halo에 등고선41개/표고점96개, 원래 권역 안15개/43개다. 5m 등고 간격과 실제 source 높이25~50.89m를 보존하고, EPSG5174→32652 변환과 원본 필드를 검증했다. 공공누리1유형이고 서울 전체 ZIP은 `/private/tmp`에만 두며 약1.4MB 지역본만 공유한다. 새 Mac에서 재다운로드가 필수는 아니다.

이 원천을 게임의 Y=0에 곧바로 더하지 않는다. 다음 전역 지형 단계는 source contour/spot의 품질·높이 기준 검토→지역 보간과 오차/빈영역 검사→미터 단위 ground API→도로/건물 기초/문/랜드마크/수목·보행/차량/회복·카메라를 같은 높이로 연결→기존 필수 보행/출입/옥상 여정 재검증이다. 현재 전체 높이 연결은 미완료다. 정확지면 대신 AWS SRTM을 적용하는 방안은 건물/수목 혼입·도심 높이 차이를 확인해 채택하지 않았다. FABDEM 작은 영역은 대안 비교로만 보존했다.
