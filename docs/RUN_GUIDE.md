탑승자·차체·카메라와 로프의 표시 시점을 맞춰 이동 중 떨림을 줄였다. 현재 일반 창에서는 실제 OS 키로 자전거·킥보드의 탑승/이동/제동/하차까지 확인했으며, 전체 시설의 OS 여정과 사용자의 체감 수용은 별도다.

**Esc → 이동 속도** 설정에 따라 탈것의 전진 최고 속도와 가속·제동도 함께 바뀐다. 초고속 보행은 걷기 8.4/달리기 21m/s이며, 이때 자전거 33.6·킥보드 42·자동차 52.5·헬기 84m/s가 게임 최고 속도다. 버스와 열차는 정류장·신호·장애물 때문에 감속하거나 대기한다. 빠른 설정에서도 건물·담장·차량 충돌, 지지면과 하차 공간 검사는 유지한다.

**Esc → 헬기 옥상 착륙지 둘러보기**는 지원되는 서울특별시청 게임 옥상의 관찰 위치로 캐릭터를 옮긴다. 헬기가 함께 날아가는 기능은 아니다. 다시 **헬리콥터 착륙장으로 이동**하면 안전한 공간을 확인한 뒤 기체를 원래 게임 착륙장으로 회수한다. 로프 하강 완료 뒤에도 기체는 이 방식으로 회수되며 실제 자동 복귀 비행으로 표현하지 않는다. 수영장·물·천막·좁은 지붕과 점유된 장소는 착륙/로프 도착지로 사용할 수 없다.

역은 원본 출구 위치와 확보한 지역 2호선 선형에 연결한 게임 공간이다. 약 338m는 그 지역 자료 구간으로 실제 두 역 사이 전체 거리가 아니다. 역 평면·배차·운임 없는 게임 개찰, 두 건물 B1과 연결통로·에스컬레이터·옥상 착륙장은 게임용 구성이다. 실제 운영·지하 연결망·비행 허가를 뜻하지 않는다.

Esc 메뉴에서는 이동과 신호·운행 시계가 멈춘다. 메뉴를 닫은 뒤 누르고 있던 이동키와 E/R을 놓았다가 새로 누른다. 막힌 공간에서 안내가 나오면 자리가 빈 뒤 다시 시도한다. 아래 날짜별 안내와 검사 수는 이전 소스의 이력이며 최신 조작은 이 절을 따른다.

개발 검사를 재현하려면 준비를 마친 저장소에서 [개별 실행 도구](../tools/run_urban_transit_acceptance.py)를 쓴다. `--help`로 suite 목록을 보고 `suite headless|native 새_태그`를 지정한다. 예를 들어 다음 명령은 별도의 그래픽 검사 창을 열며, 기존 보고서를 덮어쓰지 않는다.

```sh
python3 tools/run_urban_transit_acceptance.py --help
python3 tools/run_urban_transit_acceptance.py speed native my_mac_01
```

Godot가 기본 경로와 다르면 `SIM2SEOUL_GODOT`에 실행파일 경로를 지정한다. 결과·원시 엔진/콘솔 로그는 `data/reports/urban_transit/20261021/acceptance/`에 보존하며 같은 태그는 재사용하지 않는다. 검사 중에는 창을 직접 조작하지 않는다. 이 도구의 입력과 화면 캡처는 일반 창에서 OS 키보드로 체험한 증거와 구분한다. 저장된 공유 파일·입력·로그의 일치만 확인할 때는 `python3 tools/check_street_detail_handoff.py [--prepared]`를 사용한다.

## 이전 안내: 2026-10-20 E 탑승 안정화·전동 킥보드

[Sim2Seoul.command](../Sim2Seoul.command)를 열거나 `sh tools/run_exploration.sh run`으로 실행한다. Git 갱신 뒤에는 기존 게임 창을 새 실행기로 다시 연다. 최종 킥보드 실행·화면 검증과 일반 창의 실제 E 탑승/하차·W 이동/Space 제동을 확인했다. 검증 범위와 한계는 [WORK_STATUS](WORK_STATUS.md)를 따른다.

**Esc → 전동 킥보드 대여소로 이동**은 서울광장의 첫 게임 대여소로 간다. 킥보드는 서울광장·돌담길에 각각 1대씩 있으며, 가까이서 E를 새로 누르면 탄다. **Esc → 자전거 대여소로 이동**에서도 같은 조작으로 자전거를 이용한다.

| 키 | 자전거·킥보드 조작 |
|---|---|
| E | 빌려 타기 / 멈춘 뒤 내리기 / 대여소 가까이에서 반납 |
| W | 가속 |
| A / D | 방향 조절 |
| S | 제동, 멈춘 뒤 계속 누르면 느린 후진 |
| Space | 제동 |
| Esc | 메뉴 열기/닫기, 게임과 신호 시계 일시정지 |

대여소 밖에 잠깐 세우면 E로 다시 탈 수 있다. 내릴 자리가 막히면 기다리며 E를 다시 눌러 하차 요청을 취소할 수 있다. 내리면 Space는 원래 연속 점프로 돌아온다. 이동키를 계속 누른 채 메뉴를 닫았다면 이동키를 놓았다가 새로 누른다. 메뉴에서 E를 누르고 있었던 경우에도 E를 놓고 다시 누른다.

지나가는 사람이 잠깐 사이를 가려도 E 대상은 유지한다. 사람이 실제 탑승 공간을 차지하거나 벽·차량·다른 탈것이 막고 있으면 안내를 보고 공간이 빈 뒤 E를 다시 누른다. 공중에서는 착지한 뒤 이용한다. 자전거·킥보드·버스 중 가까운 이용 가능 대상의 안내가 나오며, 하나를 타는 동안 다른 운송수단에는 동시에 타지 않는다.

**Esc → 신호등·횡단보도로 이동**하면 대한문 앞 보도에서 신호를 볼 수 있다. 현재 7구역의 차량 15개·보행 14개 신호는 **46초 주기**로 바뀌고 남은 초를 표시한다. 차량 녹색→황색→적색과 보행 녹색이 차례로 켜지며 보행 종료 전 5초는 점멸한다. 메뉴를 닫아야 주기도 재개한다.

배치·재고·신호 주기는 게임 구성으로 실제 대여/결제·현장 주행 허가·서울 전체 교통 운영을 뜻하지 않는다. [최신 집계](../data/reports/street_detail/20261020/summary.json)와 [일반 실행/OS 조작](../data/reports/personal_mobility/20261020/normal_launch.json)을 따른다. 이 Mac의 2026-10-20 최종 인수 때는 킥보드 탑승 상태로 게임을 열어 두었다. 아래 선행 안내와 과거 검증 수치는 당시 소스의 이력으로 남긴다.

일반 실행은 **Sim2Seoul.command** 또는 `sh tools/run_exploration.sh run`이다. **Esc → 자전거 대여소로 이동**하면 캐릭터 옆으로 자전거 전체를 볼 수 있다. E로 대여하고 W 가속·A/D 조향·S/Space 제동·E 하차/반납을 사용한다. 높아진 녹색 자전거 그림 표지로 대여소를 찾는다.

## 2026-10-19 안내 이력: EXP23 거리 교통·자전거·반려견 체험

일반 실행은 **Sim2Seoul.command** 또는 `sh tools/run_exploration.sh run`이다. Git 갱신 뒤 기존 열린 창은 새 기능을 자동 반영하지 않으므로 실행기로 다시 연다. 공유 검사에는 `python3 tools/check_street_detail_handoff.py`를 쓴다. 과거 EXP22/21 고정 해시 검사 결과를 최신 기능 검증으로 대신하지 않는다.

- **Esc → 버스 정류장으로 이동**: 파란 도심01을 기다린다. 오기 전에 E로 대기를 요청할 수 있다. 정차한 버스의 앞문/가운데 문 가까이에서 E로 타며 문 앞에 있으면 출발을 기다린다. 탑승 중 E로 다음 정류장 하차를 예약하거나 열린 문에서 바로 내린다. 막힌 하차 공간은 안전해질 때까지 기다린다. 마지막 정류장은 하차 전용인 짧은 게임 운행이다.
- **Esc → 자전거 대여소로 이동**: 가까운 자전거에서 E로 빌린다. **W 가속 · A/D 조향 · S 제동/계속 누르면 느린 후진 · Space 제동**이다. E를 누르면 멈춘 뒤 안전한 곳에서 내리고, 대여소 가까이에서는 반납한다. 밖에서 잠깐 세우면 E로 다시 탄다. 막힌 하차 대기는 E로 취소할 수 있다. 탑승 중 탐험 범위 변경은 내린 후 적용한다.
- **Esc → 신호등·횡단보도 / 가로등 거리 / 반려견 산책 구간으로 이동**: 중앙선/차선과 양쪽 보행 신호, 시간대별 따뜻한 노면 조명, 개와 주인의 산책/머리 동작을 살펴본다. 산책 도착 후 잠시 주인과 개가 기다린다. 메뉴/이동 체크는 원래 배우와 버스를 멈춘다.

**Esc → 반려견 산책 구간으로 이동**으로 찾아간다. 기존 **보행자 이동** 체크를 끄면 새 사람/개도 멈춘다. 메뉴에서는 모든 산책과 동작이 정지한다. 목줄은 시각 표현이고 쓰다듬기/먹이 주기 조작은 없다. 배치/도로 가장자리 높이는 게임 창작이다. [실제 검증과 한계](WORK_STATUS.md).

### 거리 상점·밤 산책·미술관 언덕 — EXP14

**Esc → 시간대**에서 낮·해질녘·밤을 고른다. 해질녘/밤에는 돌담길의 따뜻한 가로등이 켜지고 선택을 다음 실행에도 기억한다. **진주회관 앞 거리 / 돌담길 버스킹 / 미술관 언덕 입구로 이동**으로 새 장면을 찾아갈 수 있다. 메뉴를 닫은 뒤 이동키를 놓았다 다시 누르면 걷는다.

진주회관과 GS25·이마트24·CU에는 간판·차양/상품 진열을 넣었다. 이번 추가는 외관이며 새 출입 기능은 없다. 돌담길에는 갓길 주차 차/오토바이, 기타 연주/관객과 걷고 날아오르는 새가 있다. 공연은 시각 표현으로 소리는 없다. 밤 조명·소품 위치는 게임 창작이다.

미술관 진입로는 실제 길의 수평 위치를 따라 올라갔다 내려오는 **높이3m 게임용 언덕**이다. 평평한 쉼터와 난간을 두고 기존 미술관 정문 앞은 원래 높이를 유지한다. 서울 전체의 실제 지형을 복원한 기능은 아니다. [현재 검증/한계](WORK_STATUS.md).

이 설명은 EXP14 당시 구현이다. EXP21 최신 탐험판은 위 별도3m 경사 대신 권역 공통의 보간 지면을 사용하며, [교체 이유와 높이 계약](TERRAIN_INTEGRATION.md)을 따른다.

### 움직임 안정화 — EXP13

걷기·달리기·점프 때 몸통 높이와 좌우 기울기를 고정해 잔진동을 줄였다. 발은 방향을 바꾸고 내딛을 때 부드럽게 이어지고, 카메라와 캐릭터 외형의 표시 타이밍을 맞췄다. 초고속 이동·연속 점프 조작은 그대로다. 이전 실행 창은 수정 사항을 자동 반영하지 않으므로 최신 실행기로 다시 연다. [검증과 한계](WORK_STATUS.md).

### 연속 점프와 새 걷기 동작 — EXP12

**Space를 놓았다 다시 누를 때마다** 공중에서도 이어서 점프한다. 횟수 제한은 없고, 누르고 있기만 해서는 반복되지 않는다. 승강기에서 내린 뒤 W를 계속 누르는 중에도 Space를 한 번 놓고 새로 누르면 점프한다. 옥상에서 높이 뛰었다고 출발점으로 복귀하지 않으며, 원래 건물 범위와 추락 복귀는 유지한다. 일반 실내에서는 실제 천장에 닿을 수 있다.

새 탐험 캐릭터는 팔·다리·신발이 함께 움직인다. 실제 이동에 맞춰 걷고 달리며 정지/벽 앞에서는 발걸음을 멈춘다. 공중과 시설 이용에는 별도 자세를 쓰고 Esc 메뉴에서 멈춘다. 원래 사람 크기와 충돌 범위는 그대로다. 아래 EXP08의 2회 점프 설명은 이전 구현 이력이며 현재는 이 절의 동작을 따른다.

### 음식·샤워·운동 사용하기 — EXP11

시설 가까이에서 **E**를 누르면 사용하고, 다시 누르면 그만둔다. 음식은 접시/젓가락으로 먹고 포만감이 올라간다. 샤워 부스 안에서는 물이 흐르며 청결도가 올라간다. 러닝머신은 벨트가 움직이고 달린 거리, 덤벨은 들어 올리는 동작과 횟수를 기록한다. 화면에 가까운 설비 이름과 현재 진행을 표시한다.

더플라자호텔은 **2층 뷔페 / 4층 운동실 / 5층 샤워실**이다. 식당·운동실이 있는 업무/주거·공공 건물에도 해당 장비 사용을 연결한다. 사용하는 동안 이동/점프는 멈추고 종료 후에는 키를 놓았다가 다시 누르면 움직인다. Esc 메뉴는 사용 시간과 효과도 정지한다. 수치는 게임 세션 동안 유지하는 활동 기록이며, 식사/샤워/운동 동작은 간단한 게임 표현이다. 현재 검증과 남은 한계는 [WORK_STATUS](WORK_STATUS.md)를 따른다.

### 층마다 다른 시설 찾기 — EXP10

승강장 **E**를 누르면 층수 아래에 **뷔페·피트니스·스파·교육·주방**처럼 그 층의 용도가 나온다. 스크롤하거나 키보드로 이동해 고른다. 더플라자호텔 게임 실내는 **2층 뷔페·4층 운동·5층 스파/샤워·6층 연회**로 나뉜다. 시설 표지를 따라 열린 입구로 들어가 둘러볼 수 있다.

도서관의 어린이/미디어/스터디, 업무·공공 건물의 식당/강의·운동, 주거의 세탁실/공유주방, 전시 공간의 작업실도 다른 설비를 사용한다. EXP10에서는 설비를 살펴보는 단계였고 EXP11에서 음식·샤워·러닝머신/덤벨 사용을 연결했다. 실내 탕의 목욕 동작/유체 시뮬레이션은 별도다. 실내 얕은 탕은 걸어 들어가는 공간이고 실제 부력 수영은 옥상 풀에서 사용한다. 건물별 시설/층 배치는 게임 창작이다.

### 자동문 엘리베이터와 다양한 옥상 — EXP08·EXP09

승강장 앞에서 **E → 원하는 층/옥상**을 고른다. 객실 안에서 문이 닫히고 층 표시가 변하다가 도착 후 문이 열리면 내려온다. Esc 메뉴를 열면 승차도 함께 멈춘다. 층이 많은 건물은 선택창 안에서 스크롤해 28층이나 옥상을 고르며, 키보드로 버튼을 옮겨도 해당 버튼을 보여준다. 객실 오른쪽 층 번호도 조작반 안에 들어가도록 배치했다.

옥상은 건물에 따라 **정원과 퍼걸러**, **야외 풀·선베드·파라솔**, **걸어 들어가는 펜트하우스와 테라스**가 있다. 주변 도시를 내려다보며 돌아다니다 승강장 앞 **E**로 실내층에 내려온다. 건물 밖으로 나가려면 **1층 → 출입구 E**를 사용한다. Space는 지상 점프 뒤 공중에서 한 번 더 누를 수 있다.

옥상 시설은 게임에서 만든 구성이며 실제 해당 건물의 시설 현황을 복원한 것은 아니다. 풀 옆 계단을 올라 가장자리에서 점프하면 물보라와 함께 들어간다. 물에 뜬 상태에서 WASD로 이동하고, 가장자리 쪽으로 움직이며 **Space**를 새로 누르면 물 밖으로 뛰어나온다. 물속 이동은3m/s이고 밖으로 나오면 원래 이동 속도를 사용한다. 가까운 현재 건물의 옥상 한 곳을 준비한다. [옥상 화면·검증](../data/reports/rooftops/20261016/summary.json)·[승차/점프 검증](../data/reports/lift_jump/20261016/summary.json).

### 건물마다 다른 실내 살펴보기 — EXP07

서울도서관은 **1층 종합안내·반납기·목재 서가**, **2층 생각마루·컬러 방석·개인 독서등**, 3층 디지털 열람, 4층 기록 전시로 구성을 나눈다. 신청사에는 녹화벽을 둔 시민안내와 대기석·번호표·상담 창구가 있다. 일반 빌딩은 리셉션·입주사 안내·출입 게이트와 상층의 업무/회의/휴게 공간, 호텔은 프런트·라운지와 상층의 객실 베이로 구분한다. 전시 공간·교회·주거·은행도 별도 가구와 표지를 사용한다.

엘리베이터나 계단으로 층을 바꿔 같은 건물의 다른 공간을 살펴본다. 책등·서가 번호·책상 위 책/인쇄물·독서등, 가구 마감과 바닥 줄눈은 가까이 가면 볼 수 있다. 마우스 휠로 카메라를 당기면 캐릭터가 가리던 부분을 살펴보기 쉽다. 새 소품 대부분은 시각 표현이며 반납기·번호표·게이트·객실 문을 실제로 조작하는 기능은 포함하지 않는다. 기존 E 입퇴장·계단·승강기는 계속 사용할 수 있다. 실제 현재 건물의 모든 방을 복원한 평면이 아니라 원본 크기에 맞춘 게임 공간이다. [변경과 실제 검증](../data/reports/interior_identity/20261016/summary.json).

### 여러 건물과 층 들어가기 — EXP04

출입 표지가 있는 건물 정문 앞에서 **E**를 누른다. 건물 중심과의 거리가 아니라 외벽의 출입구 너비와 앞쪽 범위로 판정하므로, 도서관 문에 바짝 붙거나 문 양옆에 서 있어도 들어간다. 짧게 누른 E도 처리하며 키를 계속 누른 것만으로 재입장하지 않는다.

**Esc → 서울도서관 정문으로 이동**을 선택하면 정문으로 바로 갈 수 있다. 도서관은 4층, 신청사는 12층이며 총 125개 건물의 게임 실내를 연결했다. 건물마다 원본 외곽 안에 들어가는 바닥 크기가 다르고 층수는 OSM 원문 또는 원본 높이 추정에 따른다. 작은 건물·사유지·일부 역사 건축물은 제외한다.

- 왼쪽 뒤의 계단을 직접 걸어서 오르내린다. 화살표 표지와 난간을 따라 두 경사 계단과 중간 참으로 연결된다.
- 앞쪽 엘리베이터 문 앞에서 **E → 층 버튼**을 누르면 해당 층으로 이동한다. 자동문 객실에서 현재 층을 표시하며 도착 후 이동키를 놓고 다시 움직인다. Esc 메뉴를 열면 이동도 정지한다.
- 1층 출입구 근처 **E**로 밖으로 나온다. 실외 복귀 지점이 모두 막혀 있으면 실내에 남는다. 메뉴의 ‘대한문 밖으로 복귀’로도 나갈 수 있다.
- 현재 층에는 걷는 사람 4명이 있으며 메뉴를 열면 함께 멈춘다. 야외의 2명·차량 6대와 구분한다.

실내는 원본 외곽에 맞춘 **게임용 재구성**이다. 실제 모든 방을 복원한 평면도나 현장의 출입 가능 여부를 뜻하지 않는다. 계단·승강기·가구와 사람 동선도 제작한 배치다. 이전 EXP03의 16×12m·1층 로비 한정은 당시 결과이며 현재 개발판은 이 범위로 확장됐다. [EXP04 결과와 화면](../data/reports/building_visits/20261016/summary.json)에 검증 조건을 남긴다. 기존 R03 ZIP은 아래와 같이 보존한다.

### 기존 R03 앱

검증된 `Sim2Seoul.zip`을 풀고 `Sim2Seoul.app`을 연다. 앱을 실행하는 데 Godot 편집기, Python, 지도 서버 연결은 필요하지 않다. 개발 저장소와 다른 폴더로 옮겨도 실행되도록 모든 게임 자료를 앱에 포함한다.

첫 위치는 대한문 밖이다. 대한문을 통과해 경내 길과 중화전 앞마당을 걷거나, 확인한 횡단 연결을 따라 서울광장·시청 전면, 남쪽 돌담길로 이동한다. 전각 실내·계단·잔디는 탐험 범위에 포함하지 않는다. 경계 밖으로 나가려 하면 안내와 차단이 동작한다.

검증한 파일은 `builds/macos/v0.1.0-fc348ad45c71-20261015T182258776232Z/Sim2Seoul.zip`이며 64,884,999 bytes다. Git에 앱/ZIP을 넣지 않으므로 다른 Mac에는 이 파일을 별도로 옮긴다. 같은 ZIP을 풀어 사용하며 다른 파일이나 새 빌드의 결과와 합치지 않는다.

```text
SHA-256 feb939b72ecd9d077b563e77aeacf0b2b8d4892dc0a00800eadc68cd65d8facb
```

## 조작

| 조작 | 동작 |
|---|---|
| WASD 또는 방향키 | 카메라를 기준으로 걷기 |
| Shift와 이동키 | 달리기 |
| Space | 약3m 점프, 공중에서도 놓았다 새로 누를 때마다 연속 점프 |
| E | 최신 개발판의 표시된 건물 정문·1층 출입구에서 진입·퇴장, 엘리베이터 앞에서 층 선택, 음식·샤워·운동 설비 가까이에서 사용/종료 |
| 마우스 이동 | 주변 둘러보기 |
| 마우스 휠 | 카메라 거리 조절 |
| Esc | 메뉴 열기, 마우스 해제, 다시 누르면 계속하기 |
| 메뉴의 대한문 밖으로 복귀 | 시작 위치로 돌아가기 |
| 메뉴의 종료 | 앱 닫기 |

메뉴가 열리면 사람·차량과 플레이어가 멈춘다. 보행자 이동과 차량 이동을 각각 끄거나 켤 수 있다. 출처 창에서 Esc나 닫기를 누르면 메뉴로 돌아가며, 한 번 더 Esc를 누르면 탐험을 계속한다.

## 화면 품질과 저장

‘기본’은 원래 해상도 배율과 그림자를 유지하고 EXP03에서는 4x MSAA와 SSAO를 적용한다. ‘가볍게’는 3D 해상도 배율을 0.75로 줄이고 그림자·MSAA·SSAO를 끈다. 두 설정 모두 실제 배치·축척·충돌과 개체 수를 유지한다. 최신 개발 탐험판은 보행자 2명·차량 6대와 카메라 원거리 1,400m이며, 기존 R03 앱은 보행자 2명·차량 2대와 200m다. 가볍게의 성능 개선 폭은 별도 측정 전에는 보장하지 않는다.

메뉴에서 고른 품질은 다음 실행에도 적용된다. 잘못된 설정 파일은 기본으로 복구하고 안내한다. 현재는 위치나 생활 진행을 저장하지 않으며, 앱을 다시 열면 대한문 밖에서 시작한다.

## 출처와 현실의 차이

화면 아래 지도 출처와 메뉴의 ‘출처 보기’를 확인할 수 있다. 상세 출처·엔진/자산 라이선스·자료와 변경 방법 안내는 앱 안에서 오프라인으로 읽는다. 공식 웹 링크를 직접 누르는 경우에는 웹 브라우저를 연다.

도로·건물의 수평 배치와 미터 축척은 공개 지도에서 왔다. 최신 EXP21은 공식 등고선·표고점의 연속 보간 높이와 게임용 건물 기초 평탄화를 쓴다. 기존 R03의 임시 평면 지면과 구분한다. 건물 높이의 원문·추정 구분, 세부 외형·문 폭·통행 연결의 제작 가정은 남는다. 현재 현장 출입 허가나 정밀 측량 결과를 표현한 앱은 아니다. 대한문 경내 보행과 EXP04의 별도 건물 실내를 구분한다. 게임 내부 크기는 원본 외곽 안의 직사각형이고 실제 모든 방·복도를 재현하지 않았다. 기존 R03 앱에는 새 실내·상층·엘리베이터가 없다.

## 다른 Mac에서

2026-10-16 새로 준비한 **Apple M5·RAM 16GB·macOS 26.6.2**에는 공식 Godot 4.7.2를 `/Applications/Godot.app`에 설치했고 Python 환경과 V0 자료도 생성했다. [최초 Mac 기동 기록](../data/reports/m5_startup_20261016.json)은 원래 V0의 GUI·준비 로그·Esc 메뉴 복귀 확인 범위다. 이후 기본 실행은 위 최신 개발 탐험판으로 바뀌었다. 기존 R03 ZIP 재검수나 전체 동선·성능 재측정은 포함하지 않는다.

동일한 ZIP의 SHA-256을 비교한 뒤 옮긴다. 앱은 로컬 ad-hoc 서명 검사를 통과했으며 배포용 Developer ID 서명·공증은 하지 않았다. 다른 Mac으로 옮긴 뒤 Gatekeeper의 최초 실행과 M4 실행은 아직 미검증이다. macOS가 실행을 막으면 표시한 앱 이름과 사유를 확인한다. 시스템 전체 보안 설정을 끄지 않는다.

M1 Pro에서의 검증을 M4 Pro 실행 결과로 보지 않는다. M4에서는 먼저 칩·RAM·OS를 확인하고 같은 앱의 기동·조작·동선·보행자·차량을 별도로 기록한다. 개발을 이어갈 때는 [다른 Mac 준비](CROSS_MAC.md)와 [현재 상태](WORK_STATUS.md)를 따른다.


기존 R03 검수 당시에는 Mac이 잠겨 실제 OS 키보드·마우스/초점 시험을 수행하지 못했다. 이후 M5 최초 기동에서는 실제 창과 OS Esc 메뉴 복귀를 확인했다. EXP02와 EXP03의 자동 물리·GPU 검사를 최신 기능 전체의 직접 사람 조작감·장시간 성능 검증으로 확대하지 않는다.

![기존 R03 앱의 대한문 시작 화면](../data/reports/r03/final/runtime/full_view_checkpoint_0.png)

새 Mac의 일반 실행은 `prepare_local_terrain.py`가 실제 지면 생성기를 호출한다. 재생성으로 달라진 준비 보고서는 Git 제외 `terrain_local_preparation.json`에 보존하고 공유된 수용 보고서는 복원한다. 실제 출력 SHA가 공유 기준과 다르면 자동 기동을 멈춰 그 Mac의 검증 없이 수용 기록을 덮어쓰지 않는다. 개발 중 원천/생성기 변경의 새 판정은 별도 작업·증거로 갱신한다.

EXP21 최신 탐험은 M1의 지속적인 계산 지연을 피하기 위해 물리 계산을 기본30Hz로 실행하며 화면 갱신은 별도다. 기존 속도 프로필과 축척은 같다.60Hz 스트레스 검사와30Hz 실제 그래픽 결과를 구분해 기록하고, 과거 V0/R03 앱의 실행 주기는 바꾸지 않는다.
