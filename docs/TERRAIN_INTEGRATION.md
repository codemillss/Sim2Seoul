# EXP21 공식 자료 기반 지형 연결

현재 덕수궁·시청 권역의 수평 위치와 미터 축척은 그대로 두고, 서울시 등고선·표고점에서 보간한 상대 높이를 탐험 장면에 연결한다. 원본 지도·건물 높이·기존 단계의 평면 입력을 덮어쓰지 않는다. 이 문서는 구현 이유와 검증 범위를 설명하며 실제 완료 여부는 WORK_STATUS와 이번 summary를 따른다.

## 높이를 만드는 세 단계

1. **공식 원천**: 서울시 「서울시 경사도」에 제공된 국토지리정보원 2023년 기준 등고선41개·표고점96개를 쓴다. EPSG5174에서 기존32652/local XZ로 변환한 작은 지역본은 그대로 보존한다. 공식 code의 등고선 종류와 오목지 구분을 원문과 함께 기록하며, 지하/교량 구조물이나 실측 출입 권한을 추정하지 않는다.
2. **보간**: 원래 등고선의 선 전체와 표고점을 이용하는 연속 거리 가중 보간을 선택했다. 촘촘한 등고선 정점 수가 가중치를 지배하지 않게 한다. 제약 없는 TIN은 일부 가까운 등고선 사이에서4.836m 오류가 생겨 채택하지 않았다. 선택한 원천 함수는 source 선·점을 재현하지만, 표고점5분할 보류 검사의 RMSE2.315m/최대8.739m를 기록한다. 독립 측량 오차나 현장 정확도가 아니다. 출력5m 격자는 보간을 표본화한 간격이며 실측5m DEM을 뜻하지 않는다.
3. **게임 기초와 상대Y**: 같은 자료의 고정 원점 높이31.362231m를 빼서 게임Y로 사용한다. 원자료의 수직 datum은 미상이며 해발 기준을 새로 확정하지 않는다.635개 source 건물은 실제 맞닿는 윤곽끼리 묶은525개 기초를 쓴다. 각 건물 자체 높이·층수·XZ는 보존하고 기초만 이동한다.302개 가까운 기초에는 추가 평탄부를 붙이지 않아 가짜 맞닿음을 막고,223개 떨어진 기초에는0.6m 여유를 둔다. 기초 높이·8m 이상 혼합과 추가 경계 연결은 게임 재구성이다. 최대 원천 대비 기초 평탄화6.523m를 감추지 않는다.

## 실제 지면과 표시를 일치시키는 방법

`prepare_terrain_surface.py`는 격자와 평탄 기초 경계에서 실제 삼각형을 나누고, 지형 삼각형의 공간 색인을 함께 만든다. `terrain_surface.gd`의 높이 조회와 충돌·표시 면이 같은 삼각형을 참조한다. 단순한 평면을 숨겨 놓고 건물만 올리는 방식이 아니다.5m 격자와 건물 모서리가 거의 일치하면 매우 얇은 삼각형의 가짜 횡경사가 생길 수 있어, 양쪽 인접 면에 같은 새 꼭짓점을 추가한다. 원본 건물 좌표를 이동하거나 지형 높이를 제한하지 않고 면적·공유 모서리를 보존한다. 실제 좁은 건물 틈의 가파른 면은 별도 기록하며 통행 가능하다고 처리하지 않는다.

탐험 장면은 기존 평면 모듈을 준비한 뒤 한 번의 동기 처리 안에서 다음을 연결한다. 중간에 물리 프레임을 진행하지 않는다.

- 기존 평면 지원과 미술관의 게임용3m 언덕을 교체하고, 원래 경계/사유지와 산책길 모드는 유지한다.
- 도로·보도·마당과 차량 전용 수평 지지면은 같은 지형 삼각형 경계에서 나눈다. 담장 같은 수직 면은 수평 변을3m 이하로 분할해 지형을 따른다. 작은 소품은 강체 이동이며, 건물·전각·상점·옥상·문에는 해당 기초 높이를 적용한다.
- 분리된 실내 셀의 자체 좌표는 유지하고, 문·지붕·물 영역·승강기 목적지를 새 기초에 맞춰 재생성한다. 바깥 발 위치는 그 XZ의 실제 지면에 맞추고, 기초와의 차이를 별도 기록한다.
- 배우의 원래 XZ/경로 거리는 유지하며 바닥 조회·이동·차체 경사·교차 사람 감지를 지면 상대 기준으로 바꾼다. 실제 이동은 기존 물리 컨트롤러를 사용한다.
- 가로수는 batch 전체를 이동하지 않고 나무별 높이로 다시 만들며, 새·거리 소품·스폰/낙하 복귀·카메라와 안내의 절대Y 가정을 없앤다.

## 재생성과 다른 Mac

공유 입력은 기존7개 지역 원천과 `terrain_heightfield.json`, 도구·코드·검증 기록이다. 서울 전체 ZIP이나 국가 지도는 필요하지 않다. `game/data/generated/terrain_surface.json`과 지형 투영 리소스 캐시는 Git 제외이며 실행기가 이 Mac에서 준비한다.

```sh
# CROSS_MAC의 최초 Python/V0 준비를 마친 Mac에서 실행
# 실행기가 지면을 만들고 공유 기준과 대조한다.
sh tools/run_exploration.sh run
```

기하 캐시는 원본 면/충돌 도형·실제 변환·엔진 버전·전체 지형 SHA·투영·높이 조회 코드 SHA에 묶인다. 자료/코드가 바뀌면 새로 만들고, 재질은 현재 장면에서 다시 적용한다. 캐시가 없거나 읽을 수 없어도 실제 투영 경로로 돌아간다. 첫 계산과 재사용의 기동 시간은 구분해서 기록한다. M1 Pro16GB의 결과를 M4나 새 export 성능으로 대신하지 않는다.

## 검증과 남은 한계

첫 작은 연결 시험은 대한문 양방향66m와 원래 미술관 길90m 양방향에서 새 실제 충돌 위의 입력 보행으로 수행했다. 원천 Y0 결과를 지형 완료 증거로 재사용하지 않는다. 최종 검증은 전체 지면/원래 경내·광장·돌담길 여정,126동 출입 후보·호텔 왕복,30개 보행 객체·14대 차량의 실제 접지/이동, 회복·점프·카메라·메뉴와 낮 native 화면을 함께 다룬다. 실패와 수정, 테스트 시작용 명시적 배치, 사람 직접 조작·다른 Mac·장시간 성능의 미확인을 원시 보고서에서 분리한다.

원천 간 시점 차이·지형 보간·평탄 기초는 남는다. 실측 도로 횡단면·계단/옹벽/지하 연결·모든 실제 문턱과 건축 기초를 조사한 결과는 아니다. 원래 건물 실내와 야외 풀도 게임 시설이며 실제 시설 현황 복원이 아니다.

캐시 검사는 서로 독립된 두 headless 기동에서2,630개 정적 노드의 변환·전체 메시 배열·충돌 도형 SHA가 같음을 확인했다. 최종 고정된 정적 장면의 첫 계산22.85초, 재사용7.30초는 해당 M1 시험의 기동 관측이며 일반 FPS나 다른 Mac 성능을 뜻하지 않는다.39개 MultiMesh 기록은 이 지문 검사에서 제외하고 native 화면의 별도 검사로 다룬다. [캐시 비교](../data/reports/terrain_integration/20261018/final/cache_equivalence.json).


보행자·차량의 안전 판정은 높이 적용 후에도 실제 물리 검사를 유지한다. 차량은 전체 지형 높이와 차체 반지름으로 기존 모든 앞길 검사 범위를 포함하는 큰 상자가 비었을 때만 정밀 계산을 생략한다. 진단 시 기존 범위를 실제로 다시 계산해 포함 관계를 검사한다. 보행자의 정적 사유지·차도·문 후보는32m 공간 색인으로 먼저 고르며, 최종 도형 포함과 엄격한 거리 비교는 원래 규칙을 그대로 사용한다. 동적 사람·차량과 물리 스윕, 사유지/차도 허용 범위를 넓히지 않는다. 원래 판정과 색인 판정은 실제 원본 경계·문 거리 경계·권역 표본에서 독립 대조한다.

새 Mac의 일반 실행은 `prepare_local_terrain.py`가 실제 지면 생성기를 호출한다. 재생성으로 달라진 준비 보고서는 Git 제외 `terrain_local_preparation.json`에 보존하고 공유된 수용 보고서는 복원한다. 실제 출력 SHA가 공유 기준과 다르면 자동 기동을 멈춰 그 Mac의 검증 없이 수용 기록을 덮어쓰지 않는다. 개발 중 원천/생성기 변경의 새 판정은 별도 작업·증거로 갱신한다.

### EXP21 지형 여정과 동적 배우의 검증 분리

전체3.3km 연속 입력 여정은 지형·건물·카메라 전용이다. 정지한 원래 NPC가 동선 위에 서 있으면 검사 자체를 막으므로, 이 fixture 안에서만44개 동적 CharacterBody layer를 임시 해제하고 모두 원래 값으로 복원한다. 플레이어 mask·원본 건물·지면·카메라 충돌은 유지한다. 별도 생산 장면의 actors 검사는30개 보행 몸체(사람28/개2)·14차량을20초간 실제 이동시키며, 이동 전과 fixture 뒤에 각각 layer·mask·활성 충돌 shape를 직접 확인한다. 이 두 결과를 살아 있는 배우와 함께3.3km를 완주한 증거나 모든 실제 교통 상황의 검증으로 확대하지 않는다.
