# W0 보행 검증판을 직접 확인하는 방법

이 안내는 W04 자동 통합 여정과 별도로 사람이 조작감·장소 인상을 확인할 때 사용한다. 현재 직접 검수 결과는 미확인이다. 실제 공사 통로·입장 조건·교통 안전을 안내하는 지도는 아니다.

## 준비와 조작

처음 쓰는 Mac은 [CROSS_MAC](CROSS_MAC.md)의 G/E/P/W 준비 순서를 따른다. W03까지 이미 준비된 Mac은 다음으로 연다.

```sh
python3 tools/prepare_walkable_itinerary.py
sh tools/run_walkable_milestone.sh run
```

일반 실행은 자동으로 캐릭터를 움직이지 않는다. WASD/방향키로 걷고 Shift로 달린다. 마우스로 둘러보고 휠로 카메라 거리를 조절한다. Esc에서 마우스를 해제하거나 문 밖으로 복귀한다. 금색 선 안이 캐릭터 중심의 이동 영역이며, 잔디·실내·계단은 이번 범위에서 제외했다.

## 확인할 여정

1. 대한문 밖에서 문을 지나 경내로 들어간다. 문에 접근할 때 카메라가 갑자기 가까워지거나 몸체가 사라지는 느낌이 불편한지 확인한다. 임시 문 외형과 실제 개구부 치수는 구분한다.
2. 경내 길에서 중화전 측면과 열린 앞마당을 다녀온다. 중화문 본체를 뚫는 대신 기존 우회 경로를 따른다. 기단·닫힌 실내·잔디를 가로지르지 않는다.
3. 석조전 계단 아래를 지나 경내 길을 돌아온다. 계단을 올라가는 기능은 포함하지 않았다. 경로를 반대 방향에서도 둘러본다.
4. 대한문 밖으로 나와 북측 보행 연결과 원문 표시 횡단을 통해 시청 전면·서울광장 외곽으로 간다. 대한문 정면에서 곧바로 차도를 건너는 연결은 만들지 않았다. 현재 차량과 신호 제어는 없다.
5. 광장의 잔디/구멍 경계에서 멈추고 돌아온다. 시청·도서관 본체의 방과 복도는 들어갈 수 없다.
6. 남측 돌담길의 연결된 구간을 왕복하고 대한문 밖으로 돌아온다. 담장 모서리에서 이동·시야가 자연스러운지 확인한다. 남측 공사의 실제 가림막과 남은 보행 폭은 미검증이다.
7. Esc 메뉴에서 캐릭터와 카메라가 멈추는지, 돌아온 뒤 키를 놓았다가 다시 눌렀을 때 움직이는지, 문 밖 복귀 후 안전하게 지면에 서는지 확인한다.

자동 검증은 약3.33km의 모든 원문 구간을 양방향으로 반복한다. 사람이 처음 느낌을 확인할 때는 같은 긴 시험을 무조건 반복할 필요는 없다. 특히 카메라 감도·문/담장 근접 시 시야·랜드마크 인상이 다음 작업의 유용한 피드백이다. 기존 사용자 위임에 따라 이 확인을 작업 진행의 승인 절차로 삼지 않는다.

## 결과를 남길 때

Mac 칩/RAM/OS·Godot 버전·해상도와 함께 불편한 장소, 이동 방향, 걷기/달리기 여부, 카메라 거리, 재현 순서를 적는다. 가능하면 화면을 함께 남긴다. “잘 된다”와 “아직 확인하지 않음”을 구분하고 자동 기록을 사람 확인으로 바꾸지 않는다.

자동 여정의 좌표·출처·실패·결과는 [W04 보고서](../data/reports/walkable_milestone.md), 현재 다음 작업은 [WORK_STATUS](WORK_STATUS.md)에서 확인한다. 보행 검증판에는 아직 간단한 NPC·차량과 완성된 랜드마크 외형이 없다. 합의한 첫 버전 V0는 후속 작업이다.
