# 사용할 자료와 보완이 필요한 부분

D04 기준: 2026-10-12. **OSM v2를 기본 배치로 사용하고, 부족한 높이·폭·지면은 출처와 추정을 구분해 보완한다.** G01 좌표 작업으로 진행할 입력은 준비됐다. 실제 게임 보행과 모든 현실 치수를 확인한 상태는 아니다.

이 문서의 수량과 후속 계획은 D04 당시 기준이다. 이후 G03에서 높이 추정·임시값·지면 예외와 단순 본체 결정을 구현한 결과는 [height_review](../data/reports/height_review.md)에 기록했다. 현재 다음 행동은 [WORK_STATUS](WORK_STATUS.md)를 따른다.

사용 규칙은 [data_usage.json](../config/data_usage.json), 실제 속성 집계는 [D04 감사](../data/reports/d04_data_audit.json), 검토 대상은 [수동 검토 큐](../data/manual/review_queue.json)다. 원본을 다시 내려받거나 일반 외형으로 실제 배치를 바꾸지 않는다.

## 높이·폭·지면의 보완 규칙

1. **높이:** G03에서 숫자/단위/의미를 검사한 원천 값, 검토한 수동 보정, 층수 환산, 임시 기본값을 구분한다. 원문·근거와 추정 여부를 보존한다. 층당 높이와 용도별 기본값은 G03에서 명시적으로 고정하며 이번 단계에서 실제값을 만들지 않았다.
2. **다중값:** `26.3;17.2`는 별동/부분 의미를 검토한다. 첫 값·최댓값·최솟값·평균을 자동 채택하지 않는다. 확인 전 해당 높이는 보류하고 생성 대안을 명시한다.
3. **핵심 랜드마크:** 대한문·중화전·석조전·돈덕전에는 본체 높이/층수 정보가 없다. 신 시청은 12층, 서울도서관은 원천 18.5m/4층이다. 궁궐에 일반 빌딩 기본값을 적용하지 않고 부속 부분·기단·지붕·비례를 따로 검토한다.
4. **폭:** 중심선을 버퍼링해 시험 폭을 만들 수 있지만 `estimated`와 적용 기준을 기록한다. 대한문 통과·담장/보도 여유·횡단 연결은 보행 검증 대상으로 남긴다. 차로 수×고정값을 실폭으로 보고하지 않는다.
5. **지면:** 지역 수직 기준은 아직 미정이다. G03에서 임시 평면을 쓰면 사용 구간과 예외를 기록한다. 로컬 y=0은 해발 0m라는 뜻이 아니다. 계단·교량·지하 구간을 모두 같은 지면에 올리지 않는다.
6. **추정과 검증:** 일반 건물의 임시 높이는 W0 준비에 허용할 수 있다. 핵심 경로를 임의로 잇거나 벽/문 문제를 추정이라는 말로 통과시키지 않는다. 기능 시험 통과와 현실 치수 확인은 별도 상태다.

## 필수 동선과 수동 검토

| 대상 | 남은 확인 | 담당 / 통과 조건 |
|---|---|---|
| R1 대한문→경내→중화전 앞→석조전 앞→복귀 | 문 개구부·전후 지면, 마당 구멍, 기단/분수 차단, 외부 통행 공간 | G03/G04에서 근거 있는 후보와 보정, W01/W02에서 양방향 완주·벽/카메라 검사 |
| R2 대한문→서울광장·시청 | 횡단 노드/웨이의 지상 연속 연결과 보도 폭/접근 상태 | G04의 실제 연결 확인 후 W02 완주. 세종대로를 가상 직선으로 관통하지 않음 |
| R3 공개 돌담길 구간→복귀 | 확인된 공개 구간, 현재 공사 영향·출입문·운영 조건 | G04에서 구간 선택, W03에서 왕복. 전체 담장 일주·대사관 통과 자동 가정 금지 |

중화전 앞 마당은 `r/10754689`의 건물 구멍을 유지한다. 석조전 앞 외부 접근은 예약 실내 관람과 구분하며, 개별 건물의 방·복도는 계속 미정이다.

2026-10-12 조사 기준 남측 담장 공사(9/21~11/19)와 평성문 통제 예정(10/25~11/19)은 날짜가 있는 참고 근거다. 남측 돌담길 전체 폐쇄나 영구 통제로 바꾸지 않는다. 구현 시점의 공지를 다시 확인하고, 현장 상태와 다른 시점의 자료를 섞으면 그 차이를 기록한다. 독립 측량 자료가 없어 위치·누락률의 현실 정확도 수치는 산출하지 않는다.

[수동 검토 큐](../data/manual/review_queue.json)의 12개 항목에는 원천 ID·증거·담당 작업·판정 기준이 있다. 승인된 보정 좌표나 높이·통과 폭은 아직 없으며 자동 생성기가 큐를 덮어쓰지 않는다. 새 보정은 원천과 분리해 재생성에도 보존한다.

## 출처와 공유 조건

사용 파일·파생 데이터에는 원천 ID·스냅샷·해시·사용/변경 범위를 보존하고 [ATTRIBUTION](ATTRIBUTION.md)을 동봉한다. 데이터의 사용 조건과 게임 코드·독자적인 자산의 조건을 구분한다. 원본 이미지/사진을 공개 열람할 수 있다는 이유로 텍스처에 넣지 않는다.

현재 국내 SHP/NGII 본체와 지도·사진 바이너리는 사용하지 않는다. 국내 원본을 나중에 받으면 실제 PRJ·DBF/인코딩·값과 그 파일의 재사용 조건을 확인한 후 사용 판정을 갱신한다. 자세한 재개 조건은 [국내 자료 조사](evidence/D03_KOREAN_SOURCE_ACCESS.md)와 [자료별 상태](../data/reports/supplemental_status.json)에 있다.

## D04 종료 당시 다음 작업 G01

이 절은 D04 당시의 인수 기준이다. 이후 G01 좌표 검증과 G02 도형 정리를 완료했으며 현재 다음 작업은 [WORK_STATUS](WORK_STATUS.md)를 따른다. [G01 결과](evidence/G01_COORDINATE_CHECK.md)는 원본·추정·수동 보완 정책을 변경하지 않는다. G02에서 정관헌·상동교회 겹침 2건을 수동 큐에 추가해 현재 검토 항목은 14건이다. D04의 12건 기록은 당시 현황으로 보존한다.

이번 사용 판정의 [검증 기록](../data/reports/d04_verification.json)은 입력/집계 검사 6개, 원천 해시·후보/제외 ID·추정값 미생성·큐 상태·문서 연결·완료 체크의 일치를 확인했다. 대형 원본이 없는 별도 파일 사본에서도 같은 집계를 재현했다. 현재 M1의 기존 도구 환경을 사용했으며 게임이나 다른 기기 검증은 아니다.

다른 Mac에서는 기본 준비 후 `python3 tools/audit_data_gaps.py --report /tmp/sim2seoul-d04-audit.json`으로 현재 지역 입력을 다시 집계할 수 있다. 미리보기/설정이 바뀌면 출처 해시 불일치로 중단하므로 현재 OSM 감사를 먼저 재생성한다. 기존 검증 보고서는 덮어쓰지 않는다.

`config/region.json`의 원점·축·1단위=1m 계약을 사용해 대표 지점 최소 3쌍의 역변환·거리·방향을 검증하고 정식 좌표 기준을 고정한다. 조사 상자는 플레이 경계나 스폰 지점이 아니다. 미수신 국내 자료·독립 측량·상세 지면 때문에 같은 취득을 반복하지 않는다. G02 도형 정리, G03 높이/지면, G04 경로 후보와 W 단계 실제 보행은 아직 미실행이다.
