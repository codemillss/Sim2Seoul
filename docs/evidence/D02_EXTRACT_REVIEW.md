# D02 지역 추출 검토 결과

판정: 완료 · 2026-10-12 · 자료 구조와 같은 국가 원본 대비 검토. 실제 보행·측량 정확도 검증은 이후 작업이다.

## 발견한 문제와 수정

기존 추출기의 관계 선택 목록에 `highway`가 없었다. 따라서 도로/보행로의 웨이는 들어왔지만, 내부에 건물·식재 등의 구멍이 있는 복합 보행 면 18개가 빠졌다. 국가 원본의 관련 multipolygon을 조립하고 조사 범위와 비교해 이 누락을 발견했다.

관계 선택에 `highway`를 추가했다. 미리보기에서도 `area=yes`가 없는 multipolygon 보행 면을 처리하도록 수정했다. 기존 노드·웨이를 유지하며 국가 원본에서 18개 관계와 필요한 참조를 추가한 새 파일을 만들었다. 원본과 이전 지역 추출물은 보존했다.

| 항목 | 수정 전 | 수정 후 |
|---|---:|---:|
| 지역 추출 크기 | 187,286 bytes | 188,346 bytes |
| 노드 | 14,481 | 14,571 |
| 웨이 | 2,137 | 2,146 |
| 관계 | 72 | 90 |
| 미리보기 보행 면 | 51 | 69 |
| 건물 / 부분 도형 | 711 / 83 | 711 / 83 |
| 국가 원본 대조에서 발견한 누락 관계 | 18 | 0 |

현재 사용할 파일은 `data/raw/deoksugung_cityhall-v2.osm.pbf`다. 이전 `data/raw/deoksugung_cityhall.osm.pbf`는 비교용이며 구현 입력으로 계속 사용하지 않는다.

## 확인한 내용

- 노드·웨이·관계 전체를 다시 읽고, 참조 누락·ID 중복·잘못된 노드 위치가 없음을 확인했다.
- 지역 객체 전체의 좌표·태그·버전·노드 순서·관계 구성원/역할이 날짜 고정 국가 원본과 일치했다.
- 조사 경계를 가로지르는 웨이 211개가 잘리지 않고 전체 구성원을 유지했다.
- 지역에서 면 조립을 기대한 객체 1,061개가 모두 조립됐다. 조립된 지역 면의 비유효 도형과 오류도 없었다.
- 국가 원본의 관련 multipolygon 14,797개를 검사했다. 조립에 성공한 면을 조사 상자와 교차/포함 비교하고, 지역 구성원의 부모 관계를 반복 추적했다. 포함 대상으로 발견한 관계 90개가 현재 지역 파일에 모두 있다.
- 대한문·중화전·석조전·돈덕전·서울시청·서울도서관·서울광장 7개 대상의 면이 정상 조립됐고 조사 범위 안에 있다.
- 복구한 보행 면 18개의 내부 링 40개를 보존했다. 중화전 앞 보행 면 `relation/10754689`와 중화전 건물 `way/181574577`은 면적이 겹치지 않는다. 건물 자리를 마당 면으로 채우지 않았다는 데이터 검증이다.
- 총 13개 검사 통과. 현재 결손을 이유로 추가 추출할 필요는 없다.

## 남은 한계

국가 원본의 관련 multipolygon 중 37개는 조립되지 않았다. 이들에서 현재 지역 구성원과의 연결은 발견되지 않았으나, 조립 불가 객체의 위치를 확정할 수 없어 원본 전체의 완전성을 주장하지 않는다. 같은 OSM 원본끼리의 검증이므로 외부 측량 대비 정확도·현재 접근 가능성을 증명하지도 않는다.

높이·도로폭·지형·출입 조건은 D03 이후, 건물/부분 도형 중복과 게임용 기하는 G02 이후, 실제 대한문 통과·충돌은 W 단계에서 검증한다.
