# D03 국내 공식 건물·지형 자료 접근 확인

확인일: 2026-10-12. 조사 범위: `[126.971, 37.5608, 126.9815, 37.5694]` 덕수궁·시청 주변. 목록·안내 확인, 실제 파일 수신, 실제 속성·좌표계 검증을 구분한다.

## GIS건물통합정보

- 공식 등록: https://www.data.go.kr/data/15083092/fileData.do
- 원본 공급 페이지: https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=NA&dsId=18
- 공공데이터포털은 SHP, 무료, 공공누리 제1유형(출처표시), 기관자체 다운로드를 명시한다. 기관별 구축 차이가 있어 참고용이라는 한계도 명시한다.
- VWorld 페이지는 in-app browser에서 정상 열람했다. web fetch는 접근 오류, sandbox curl은 DNS 해석 실패였다. 이 실패는 공급 사이트나 데이터 부재를 뜻하지 않는다.
- 미로그인 공개 목록에서 서울특별시 SHP **전체데이터 129 MB**, 기준일 **2026-10-09**, 갱신일 **2026-10-11**을 확인했다. 정확한 수신 bytes는 본체 미수신으로 미확인이다. 서울 행의 DOM 버튼은 `listFnc.download('20171128DS00010', '4545', '132580')`였다. 마지막 인수는 화면 표시에 연관된 값이며 수신 크기로 쓰지 않는다.
- 시·도 서울 선택은 가능하나 시·군·구 선택은 disabled였다. 중구/종로구만의 실제 파일이나 bbox 다운로드 경로를 확보하지 않았다.
- 다운로드 접근 조건은 실제 버튼으로 확인했다. **8,156 bytes 표시의 소용량 전국 변동자료** 버튼을 눌러도 **“로그인 후 이용해주세요.”** 모달이 나타났다. 인증이나 계정 로그인은 수행하지 않았다. 서울 본체 직접 다운로드 URL은 확인하지 못했다.
- 공개 안내는 고용량 다운로드에 **라온K 다운로드 솔루션 설치 필요**를 명시하고 https://www.vworld.kr/raonkupload/agent/raonkSetup.exe 를 제공한다. 설치는 수행하지 않았다. `.exe` 링크만으로 Mac 불가능을 확정하지 않는다. macOS 지원·대안 다운로더는 미확인이다.
- 공급자 배포 메타데이터는 **GRS80, EPSG:5186(기준일 2023-08-08 이후)** 및 **BESSEL, EPSG:5174(기준일 2023-08-05까지)**를 명시한다. 본체 `.prj`를 읽은 결과가 아니므로 실물 CRS 검증은 남아 있다. 일반 공간정보 메타데이터의 Bessel 표기와 최신 배포 좌표계 표기를 혼동하지 않는다.
- 공급 페이지 라이선스 버튼은 **CC BY**였다. 포털의 공공누리 제1유형 표기와 함께 보존하며, 취득 후 원본·가공물의 출처표시를 유지한다. 실제 파일 내 추가 조건은 본체 미수신으로 미확인이다.

## 공개 컬럼 정의서

- 페이지에서 확인한 정적 링크: https://www.vworld.kr/contents/국가중점데이터_컬럼정의서(26.08.19)_배포용.xlsx
- browser `downloadMedia` 요청은 장시간 반환하지 않아 중단했다. 해당 시도를 성공 취득으로 기록하지 않는다.
- **root가 별도로 직접 취득한 파일**: `data/raw/supplemental/korean/20261012/vworld-columns-20260819.xlsx`
- root 전달 검증값: HTTP 200, **224,314 bytes**, SHA-256 `403ba657f9c2b112445793679be5d6571e8f91fd8e6df35097476a64cb48df54`, ZIP CRC 정상. 시트는 전체/변동/참조코드/용도지역지구정보 4개.
- 이 담당은 root의 취득값을 인계받아 기록했으며 독립 재검사나 GIS건물통합 필드 파싱은 수행하지 않았다. 실제 높이·지상층수·지하층수의 필드 정의는 root의 XML 파싱 결과를 따른다. 정의서 확보는 서울 본체·높이값 확보 완료가 아니다.

## NGII 연속수치지형도

- 공식 등록: https://www.data.go.kr/data/15059721/fileData.do
- 공식 공급 연결: http://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total
- 대용량 전송 안내 연결: https://map.ngii.go.kr/ic/notice/noticeView.do?notice_id=1408
- 공식 등록 설명은 사용자 원하는 영역 신청, 1:5,000·1:25,000, SHP 또는 NGI를 명시한다. 이용법은 포털 통합검색 → 결과/마커 선택 → 연속수치지형도 → 다운로드이며, **다운로드 로그인 필요**와 **대용량 파일전송 소프트웨어 필요**를 명시한다.
- 무료·공공누리 제1유형(출처표시)은 등록 페이지에서 확인했다.
- 공급 페이지와 전송 공지는 web fetch에서 접근 오류로 본문을 확보하지 못했다. 추가 탐색은 root 지시에 따라 중단했다. NGII 실제 로그인 모달, 다운로드 URL/크기, 덕수궁 지역 계층, 도엽, 필드, 실물 CRS, Mac 지원은 **미확인**이다.
- 연속수치지형도는 등고선/표고 보완 후보이며, 아직 DEM/DSM 취득이나 지형 정확도 검증을 수행한 상태가 아니다.

## 재개 조건과 인수

1. VWorld에서 사용자 로그인과 다운로드 환경이 준비되면 현재 서울 전체데이터를 취득한다. 키 없는 정적 공개 본체 URL은 확인하지 못했으므로 공개 취득 가능으로 주장하지 않는다.
2. 받은 ZIP의 수신 크기·SHA·CRC와 `.shp/.shx/.dbf/.prj`·인코딩을 확인하고, 실물 `.prj`를 기준으로 bbox 추출한다. 높이·층수는 정의서와 실제 결측·0값·중복을 대조한다.
3. Mac 다운로드 환경이 제공되지 않으면 공식 지원 방법 확인 또는 다른 기기 취득 뒤 원본 전달을 검토한다. 설치·로그인·동의는 이번 조사에서 실행하지 않았다.
4. NGII는 로그인·공식 전송 도구 접근을 준비한 뒤 필요한 지역만 요청한다. 지역 계층과 Mac 지원은 그때 확인한다.

이번 담당은 기존 프로젝트 파일·Git을 수정하지 않았다. 본 보고서와 JSON만 작성했으며, 컬럼정의서 원본 수신은 root 담당이다. 서울 SHP와 NGII 본체는 미수신이다.
