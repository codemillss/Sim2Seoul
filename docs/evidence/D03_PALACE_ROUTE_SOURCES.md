# D03 덕수궁 공식 배치·접근 출처 조사

확인일: 2026-10-12. 공식 궁능유적본부와 서울시 발표 자료를 제한적으로 확인했다. 사진·지도 이미지를 게임 자산으로 수집하지 않았다. 이 문서는 경내 방문 목적지·관람 조건·제한 공지의 근거이며, 실제 측량·전 경로 개방 확인·게임 보행/충돌 검증 결과가 아니다.

## 이번 확보 결과

공개 HTML 10개와 공식 관람코스 지도의 식별 메타데이터 3개를 `data/raw/supplemental/palace/20261012/`에 로컬 참고용으로 확보했다. URL, HTTP 상태, 크기, SHA-256은 해당 폴더의 `source_manifest.json`에 있다. HTML에 일반 세션/설문 토큰 등이 포함되므로 원본 HTML의 저장소 공개를 권하지 않는다. 지도·사진·영상 바이너리 파일은 저장하지 않았다.

처음의 제한 환경 HTTP 요청은 DNS 오류였으나, 동일한 공개 URL에 대해 승인된 네트워크 요청으로 HTTP 200 및 실제 본문을 확보했다. 이미지 직접 URL은 web 도구가 `application/octet-stream`을 처리하지 못했으므로 공식 관람코스 페이지를 배경 브라우저로 확인했다. 지도 이미지가 `complete=true`, 2016×1356으로 로드되었으며, 화면에 대한문·금천교·중화문·중화전·석조전·돈덕전 등 명칭과 통행로 도식이 표시되었다. 화면 캡처와 원본 지도 이미지는 로컬 파일로 저장하지 않았다.

## R1: 대한문 → 경내 통행로 → 중화전 앞 → 석조전 앞 → 대한문 복귀

P01에서 대한문은 정문으로 안내되고, 지도에서 금천교를 지난 내부 통행로가 중화문과 중화전 앞 마당으로 이어진다. 중화전 권역의 옆길과 석조전 앞 정원/광장 주변 도식은 서로 연결된 경내 보행 목적지를 설정할 근거가 된다. **D04의 보행 경로 후보**로 대한문 통과, 금천교, 중화문/중화전 앞 마당, 석조전 앞 외부 통행 공간, 같은 경내 길을 이용한 대한문 복귀를 둘 수 있다. 도식상 선을 그대로 지오리퍼런싱하거나 길 폭·계단 높이로 쓰지는 않는다.

P02는 덕수궁 일반 관람을 09:00~21:00(입장마감 20:00), 정기휴일을 월요일로 안내한다. 공휴일과 겹칠 때의 휴일 예외가 있다. 석조전은 09:30~17:30(마지막 해설 16:30), 인터넷 사전예약과 해설사 동반의 제한관람으로 별도 분류되어 있다. **석조전 앞 외부 접근과 석조전 1·2층 실내 진입은 다른 계약**이다. 실내 방/복도 자유 진입 또는 지층 관람 조건은 이번 조사에서 확정하지 않았다.

2024-05-06 공지의 중화전 월대 출입 금지만 읽으면 현재 닫힘으로 오판할 수 있다. [당시 통제 공지](https://royal.khs.go.kr/ROYAL/contents/R403000000.do?id=20240506110242161636&schBcid=notice01&schM=view)는 P05의 2024-08-20 재개 공지로 갱신된다. 다만 R1의 필수 목적지는 중화전 **앞**으로 정하여 월대 계단과 전각 실내 진입을 필수 경로에 포함시키지 않아도 된다. 이번 조사에서 중화전 실내 상시 진입 조건은 확인하지 않았다.

남은 확인: 대한문 문 개구부와 실제 통과 폭, 금천교/계단/월대 높이, 중화문 통과와 옆길의 장애물, 석조전 앞 잔디/분수·기단과 실제 통행 공간 분리, 좌표와 보행 경로 폭. 공식 도식은 정성 대조용이며 OSM와 독립 좌표자료·필요한 수동 근거로 별도 검토해야 한다.

## R2: 대한문 → 확인 횡단 연결 → 서울광장·시청

P03은 시청역 2번 출구에서 덕수궁까지 도보 2분 접근을 안내하지만 서울광장 방향의 지상 횡단시설 위치·차도 횡단 방법을 확정하지 않는다. 대한문과 서울광장이 가까이 있다는 이유로 직선 횡단 경로를 만들 수 없다. 이 담당 조사에서 R2의 **정확한 횡단보도 좌표와 현재 지상 연속 보행 연결은 미확정**이다.

D04에서 실제 지역 자료의 crossing/traffic_signals/footway와 보도 연결을 확인하고, 지상·지하를 구분해야 한다. 서울광장과 신 시청 외부 접근을 R2의 목적지로 두되 시청 실내 또는 지하철 통로를 자동 개방하지 않는다. 현재 공식 페이지의 접근 안내는 일반 방문 가능성의 근거이며 게임 경로 연결 검사의 대체가 아니다.

## R3: 공개 돌담길 구간

P07은 2018년 12월 7일 영국대사관 후문~정문 사이 70m 연결과 기존 100m 구간을 설명한다. 연결 일부는 덕수궁 안쪽 보행로이며 당시 09:00~18:00, 월요일 휴관으로 안내했다. 이는 경내 일반 관람과 돌담길의 분리된 동선을 이해하는 과거 근거다. 영국대사관 부지를 자유롭게 통과하거나 경내 관람 영역과 경계 없이 합치는 해석은 부적절하다.

**2026-10-12 시점 관련 제한:** P06은 2026-09-21~11-19 남측 외곽담장(대한문~운교터)과 평성문 지붕 공사를 안내한다. 평성문 통제는 **10-25~11-19 예정**이며 현장 사정에 따라 기간이 바뀔 수 있다. 오늘 이미 평성문이 통제됐다고 읽거나, 남측 돌담길 전체가 폐쇄됐다고 확대 해석하지 않는다. 본문은 공사와 예정 출입문 통제를 말하며 모든 구간의 보행 금지를 선언하지 않는다.

R3의 첫 구현은 대한문 부근에서 이어지는 공개 보도/돌담길 중 독립 자료로 연결이 확인된 구간으로 제한한다. 전체 1,100m 순환, 북측 70m 안쪽 연결과 운영시간의 2026 현재 상태는 아직 미확정이다. 공사 가림막·출입문·폭 변화는 D04 수동 보완 기록에 날짜와 추정 범위를 표시한다. ‘공개돌담길’이라는 명칭은 모든 문이 항상 열린다는 뜻이 아니다.

지도 메타데이터 수정일은 실제 측량일이나 모든 시설 갱신일이 아니다. 표시 URL이 열리거나 다운로드 버튼이 있다는 사실은 게임 재사용 허가가 아니다.

P08은 개별 공공누리 표시를 확인하도록 하고, 미표시 자료는 사전 협의 대상으로 안내한다. P09는 일반 홈페이지 사진자료와 전체 내용 복제에 대해 제한적으로 답한다. 한편 **브라우저에서 선택된 ‘대한문 전경’ 상세 사진 저작물**에는 공공누리 제1유형과 ‘이 저작물만 다운로드’가 표시됐다. 그 개별 저작물은 구체적 출처를 붙이는 조건의 재사용 후보로 볼 수 있지만, 그 표시를 위의 전체 지도·다른 사진·지도에서 파생한 게임 텍스처에 자동 적용할 수 없다. 이번에는 사진 다운로드를 진행하지 않았다.

따라서 현재 자료 상태는 **공식 배치·명칭·접근 제한 참고 근거 확보 / 지도 자산 게임 재사용 권한 미확정 / 개별 대한문 사진 KOGL1 표시 확인 후보**다. 재사용할 때는 해당 파일과 대응되는 허가 표시·작성연도·제작기관·저작자·URL을 함께 보존한다. 문의 후보는 공식 정책의 궁능서비스기획과 저작권 담당 02-6450-3827, 사진·영상 담당 02-6450-3859다. 문의를 보내지는 않았다.
