# G02 도형 정리와 원천 연결

2026-10-12, 현재 M1 Pro의 기존 데이터 환경에서 실행했다. **원본 도형 1,523개를 미터 좌표로 옮겨 원천·내부 구멍·부모/부분 역할을 보존했고, 정상 입력 26개 검사와 변형 입력 9개 거부를 통과했다.** 다음 작업은 G03 높이·지면 분류다. 게임·메시·충돌은 아직 없다.

## 입력과 산출

현재 OSM v2, G01 고정 좌표 기준, D04 사용 정책·수동 큐, Overture 2026-09-23.1 소구역을 재사용했다. 원본 다운로드나 수정은 하지 않았다. 국내 SHP/NGII 본체는 계속 미수신으로 독립 건물 대조를 수행하지 못했다.

- [prepare_features.py](../../tools/prepare_features.py): `data/processed/features.json`을 생성한다. 6MB급 재생성 가공물이므로 Git에 넣지 않는다.
- [geometry_rules.json](../../config/geometry_rules.json): 링 방향·생성 역할·겹침/보류 기준을 고정한다.
- [check_geometry.py](../../tools/check_geometry.py)와 [검사 결과](../../data/reports/geometry_check.json): 원천·도형·기준·부모 관계·후속 속성을 대조한다.
- [회귀 검사 도구](../../tools/test_geometry_contract.py)와 [변형 거부 결과](../../data/reports/g02_regression_check.json).
- [별도 작업 사본 검증](../../data/reports/g02_verification.json): 재현·수동 큐 유지·문서/상태 일치.

가공물은 EPSG:32652에서 고정 원점을 뺀 `[x,z]` 미터 좌표를 명시한 **독자 JSON 형식**이다. 원본 위경도·EPSG:4326·태그·노드/관계 참조를 별도로 보존한다. 원점을 다시 계산하거나 bbox에서 자르지 않는다. y·지면·높이·폭·게임 접근 허가는 미배정이다. XZ 링은 외곽 반시계/구멍 시계로 정규화하되 Godot 앞면·법선은 아직 검증하지 않았다.

## 검사 결과와 생성 역할

| 원본 종류 | 보존 수 | G02 역할 |
|---|---:|---|
| building | 711 | 기본 본체 후보 635, 지붕 참조 72, 미설명 겹침 보류 4 |
| building_part | 83 | 부분 참조, 독립 일반 건물로 동시 생성 금지 |
| highway 선 / 면 | 409 / 69 | 원본 중심선 / 태그 면, 실제 폭·통행 검토 전 |
| barrier 선 / 면 | 47 / 13 | 같은 원천 선/면 10쌍은 면을 참조로 구분 |
| gate / land_area | 13 / 178 | 문 위치 후보 / 토지 참조, 실제 문 개구부·지면 아님 |

모두 유효하고 원본 종류·다각형 수·내부 구멍 **83개**·면적·선형을 보존했다. 수리/도형 삭제/bbox 절단은 0건이다. 링 방향 정규화 외에 도형을 바꾸지 않았다. 전체 원본 정점 역변환 최대 오차는 `2.13e-14`도다. 현장 측량 오차가 아니라 변환 구현 결과다.

명시 `type=building` 그룹은 3개다. 석조전 `r/19357702`는 외곽 `r/19357693`와 부분 33개를, 서울도서관 `r/18722760`은 외곽 `r/10757525`와 부분 4개를, 다른 그룹 `r/18722758`은 외곽 1개와 부분 1개를 연결한다. 석조전 관계에 없는 부분과 도서관 상단 부분 2개는 공간 후보를 별도로 남겼다. 겹침만으로 실제 부모 관계를 확정하지 않는다.

석조전의 **명시 부분 33개 합집합**은 외곽 약 50.15㎡를 덮지 않고 약 1.88㎡가 밖으로 나간다. 부분을 자동 확대/절단하거나 빈 곳을 채우지 않는다. 도서관 명시 부분 합집합은 외곽을 덮는다. 부분끼리 겹치는 82쌍은 층·지붕·기둥 표현일 수 있어 min_height/height를 G03에서 검토한다. 본체와 공간상 겹치지 않는 부분 20개도 부모가 없다는 확정이 아니다.

관계 outer 웨이가 별도 building/part로 다시 등장한 사례와 같은 유형·같은 태그의 완전 동일 도형 별칭은 현재 각각 0건이다. 검사 규칙은 이후 자료에서도 유지한다. 높이 의미가 다른 동일 평면은 단순 별칭으로 없애지 않는다.

## 보류한 것

다음 두 본체 겹침은 일부가 같은 건물의 다른 부분인지 판단할 근거가 부족하다. 원본을 모두 보존하고 **4개 외곽을 기본 본체 후보에서만 보류**했다. 필수 랜드마크 본체 6개와 서울광장은 유지된다.

| 원본 쌍 | 겹친 면적 | 처리 |
|---|---:|---|
| w/1128365145 · w/1128365153 (상동교회) | 약 189.22㎡ | 양쪽 보류, G03/수동 검토 MR14 |
| w/381755268 · w/776767573 (정관헌) | 약 339.05㎡ | 양쪽 보류, G03/수동 검토 MR13 |

72개 `building=roof`도 자료에서 삭제하지 않고 지붕 참조로 남겼다. 기본 본체와 동시에 일반 빌딩으로 높여 세우지 않는다. 635개 본체 후보 사이에는 0.01㎡ 기준을 넘는 미설명 겹침이 없다. 이 수량은 현실 건물 개수나 최종 표시 수가 아니다.

Overture 비OSM 후보 22개 모두 원천·유효성·면적·OSM 겹침을 비교했다. 현재 존재·별동/부분 여부를 독립 확인하지 못해 전부 기본 도형에 추가하지 않고 사유와 원천을 보존했다. 후보를 보류했다고 현실 건물이 없다는 뜻은 아니다. DSM·공식 안내 이미지는 게임 자산으로 사용하지 않았다.

## 실패·수정과 검증 강화

첫 원문 태그 대조에서는 면 조립기가 relation의 `type=multipolygon`을 생략한 83건을 오류로 잡았다. [초기 실패 증거](../../data/reports/g02_before_review.json)를 보존하고, 그 한 필드만 생략된 경우 원본에서 복원했다. 다른 태그 차이는 계속 중단한다. 최초 검사 JSON의 NumPy 불리언 직렬화 실패도 Python bool 변환으로 수정했다.

독립 Sol 검토에서 그룹/역참조를 모두 지우거나 높이 원문·좌표계 표기·내장 설정을 바꿔도 통과하는 검사 누락을 발견했다. 원본 기대 그룹 집합·역참조, 높이/최저높이/층수/지붕/도로/접근 원문, CRS·축·좌표 설정·원문 설정·역할 집계를 추가했다. 그룹 삭제, 높이 원문 변경, 원본 CRS 변경, 내장 규칙 변경, 원점 메타데이터 변경, 마당 구멍 채움, 대한문 정점 이동, 본체 목록 중복, 부분을 독립 본체로 추가한 **9건 모두 필요한 검사에서 거부**했다.

중화전 앞 보행 면 `r/10754689`의 구멍이 건물 면을 채우지 않는지도 수치로 검사했다. [관계 도형 검토 그림](../../data/reports/g02_geometry_overview.svg)을 PNG로 렌더해 부모/부분·지붕·마당 구멍과 축척/표기를 확인했다. 이는 도형 관계 그림이며 실제 조감도나 통행 검증은 아니다.

## 다른 Mac에서 재현

기본 준비 도구가 미리보기·G01 좌표 기준 뒤에 G02 생성/검사를 실행한다. 기존 환경에서는 다음을 사용한다. 전국 원본·추가 D03 의존성·게임 엔진은 필요 없다.

```sh
.venv-data/bin/python tools/prepare_features.py
.venv-data/bin/python tools/check_geometry.py --report /tmp/sim2seoul-g02-check.json
.venv-data/bin/python tools/test_geometry_contract.py --report /tmp/sim2seoul-g02-regression.json
```

원본/설정이 바뀌면 미리보기·G01을 먼저 재검증해야 한다. 수동 큐의 기존 12건에 G02 확인 메모를 남기고 겹침 보류 MR13/MR14를 추가해 현재 14건이다. 승인된 보정 좌표·치수는 없다. 정관헌 등 보류 도형은 실제 공간에서 삭제된 것이 아니며 G03 전에 해결/역할 결정을 이어간다. 가공 도형·부모 역할을 현장 위치 정확도·최종 높이·보행 가능성·게임 성능으로 확대 해석하지 않는다. W0/V0 및 M4 실행은 미검증이다.
