# L01 랜드마크 외형 제작 기준

기준일: 2026-10-15. W04 커밋 `1922c70c6e1a569b0f980beaaf5742906b7de340`의 보행 공간을 유지한다. **이번 결과는 참조·제작 명세이며 새 외형을 구현한 결과가 아니다.** L02는 궁궐, L03은 시청·광장·주변 빌딩을 만들고 L04에서 장소 인지와 보행을 함께 확인한다.

위 기준일과 본문의 L01 표현은 당시 명세 기록이다. 후속 L02/L03 구현과 2026-10-16 EXP02 외형 보완은 아래 별도 절에 누적하며, 현재 실행/검증은 [WORK_STATUS](WORK_STATUS.md)를 따른다.

사용자가 원한 전통과 현대 서울의 공존을 위해 궁궐만 따로 꾸미지 않는다. 큰 지붕·기둥·기단과 유리·석재·빌딩 실루엣의 차이를 먼저 만들고, 작은 문양과 창문 수는 이후로 둔다. 이름표만 바꾼 상자는 랜드마크 완료로 보지 않는다.

## 명세와 원천의 경계

- [수동 제작 결정](../data/manual/landmark_plan.json): 대상·최소 특징·생략·대안·충돌 보존·검토 시점. 생성기가 덮어쓰지 않는다.
- [참조 목록](../data/manual/landmark_references.json): 공식 URL·열람 방법·시점·이용표시·짧은 사실/사진 관찰. 확인한 내용과 제작 판단을 구분한다.
- `data/processed/landmark_spec.json`: 위 결정과 준비된 G02/G03/E03/W04 데이터를 [생성기](../tools/prepare_landmark_spec.py)로 연결한 로컬 산출물. 원문 도형·높이 분류·근거 ID·해시가 들어 있다. 이 파일과 다른 자동 가공물은 Git 제외이며, 수동 입력과 생성기를 공유해 다시 만든다.
- [검사 결과](../data/reports/landmarks/l01_validation.json): 원천 연결·해시·명세 범위·동일 생성·이전 소스 보존. 실제 모델의 인지성이나 게임 회귀 시험 결과는 아니다.

숫자 높이는 G03 그대로다. 대한문10m·중화전12m·중화문5m·돈덕전14m·정관헌6m는 **임시값**, 신청사40.2m는 **12층에서 추정**, 석조전17.5m는 **명시된 부분 상단에서 도출한 외곽 상한**, 도서관18.5m·서울파이낸스센터124m는 **OSM 속성**이다. 어느 것도 이번에 독립 측량한 값이 아니다. `height_class`와 `assumption_id`를 지우지 않는다. 사진이나 ‘칸’ 수를 미터로 환산하지 않는다. 광장 면의 표시 오프셋도 실제 표고가 아니다.

|---|---|---|

| SFC 높이·정체성 | 기존 OSM124m/28층/주소36/시작2001, 소유자 주소136 및 설계사130m/지상30층/완공2000 | 값을 혼합하지 않는다. L03에서 동일 구조·높이 기준/지붕 포함·층수 의미를 비교하고, 바꾸면 별도 근거와 회귀 검증을 남긴다. 미해결이면 일반 부피 유지 |

**확인일, 페이지 갱신일, 건물 사건일, 사진 촬영일은 다르다.** 이번 개별 사진 촬영일은 모두 미확인이다. URL의 연도 디렉터리나 저작권 연도를 사진 날짜로 쓰지 않는다. 최신 웹페이지의 도면도 측량 도형이나 현재 통행 허가가 아니다.

## 외형과 보행의 결합 규칙

1. 좌표·원점·축·단위·원본 footprint/구멍·기존 높이 외곽을 유지한다. 사진 기준의 위치 이동이나 눈대중 재축척을 하지 않는다. 기존 라벨 위치는 출입구/모델 원점이 아니다.
2. 외형만 교체하며 원래 정적 충돌과 경계는 보존한다. 원본 시각 자식을 숨기더라도 부모 body·layer/mask를 함께 끄지 않는다. 석조전 등은 부모/부분 중 하나의 시각 전략으로 교체하고 전체 부피를 이중 표시하지 않는다.
3. 대한문은 W01의 **폭3m×높이3m 임시 개구부와 앞뒤 경로**를 비워 둔다. 이 수치는 현실 문 실측이 아니다. 중화문은 닫혀 있고 경내 우회 경로를 유지한다.
4. 열주·포치·난간은 새 실내/발코니/계단 보행을 뜻하지 않는다. 기존 충돌이 닫힌 곳에는 막힌 후면을 유지하고, 통과할 수 있어 보이는 틈과 실제 차단의 불일치를 L04에서 확인한다.
5. 처마·기둥·식재를 플레이어/카메라 통로에 침범시키지 않는다. 카메라가 장식에 반응할지 정할 때 시각·충돌·탐색 마스크를 함께 검토한다. 시각 외형 변경을 완료한 L02/L03/L04에서 W04 회귀 시험이 필요하다.
6. 높이 변경이나 새 지형·통로가 필요하면 기존 참조의 단순화와 분리해 기록한다. 이번 명세는 이를 승인하거나 자동 적용하지 않는다.

## 다음에 확인할 화면

수동 계획의 `review_views`는 **기존 W04 체크포인트 6곳의 검토 후보**다. 새 카메라 장면이나 가시성 통과 증거가 아니다. 가림이나 거리 때문에 한 장면에서 안 보이면 해당 지점에서 카메라를 돌리거나 후속 검토 시점을 별도로 기록한다.

## 재현과 확인

W04까지 준비된 현재 Mac:

```sh
python3 tools/prepare_landmark_spec.py
python3 tools/prepare_landmark_spec.py --check
python3 tools/check_landmark_spec.py --output /tmp/sim2seoul-l01-check.json
```

처음 쓰는 Mac은 [CROSS_MAC](CROSS_MAC.md)의 G/E/P/W 준비를 먼저 따른다. 이번 작은 사본 검사는 준비된 입력98개/약18.5MB로 표준 Python `-E -S -B`에서 같은 명세를 두 번 생성했다. GIS 전체 재구축·새 환경 설치·다른 기기 실행 검증이 아니다. **L01에는 게임 변경이 없어 GPU 보행을 재실행하지 않았다.** W04 게임/좌표/지면/충돌/경로·기존 도구/원본의 바이트 보존과 새 명세의 연결을 검사했다.

독립 검토에서 단일 지붕 층을 홑처마로 오해할 수 있는 용어를 수정했다. [수정 전 명세 입력·검사와 이유](../data/reports/landmarks/development/roof_term/review_finding.json)는 보존했다. 최종 검토는 [독립 검토 기록](../data/reports/landmarks/independent_review.json)에 연결한다.
## L03 추가 검토와 실제 자산 선택

L01 명세와 입력 해시는 보존하고, 후속 판단은 [l03_city_decisions.json](../data/manual/l03_city_decisions.json)에 별도로 남겼다. [실제 모델 비교/화면](../data/reports/city_landmarks.md) 후 배경 빌딩1곳에 Kenney CC0 수정 모델을 사용하고 시청/도서관은 독립 단순화했다. 사진·도면 파일을 도입한 것은 아니다.

신청사의 공식13층/지하5층 설명은 기존12층 기반40.2m 추정을 대체할 미터 측량값이 아니다. SFC 공식130m·30지상층·주소136·완공2000과 기존124m·28층·주소36·시작2001도 해소되지 않아 원본 높이/분류를 유지했다.

추가 참조 C07 [서울광장2025년 정비 설명](https://plaza.seoul.go.kr/archives/1041)은 목재 포장/길과 식재 변경을 보여준다. 페이지 수정일2026-02-05와 공사 연도2025를 구분한다. 사용신고 안내도의 길/무대도 좌표·축척이 확보되지 않아 내부 지형/동선을 바꾸지 않았다. 현재 잔디 타원과 안쪽 포장 테두리는 단순 표시이며 정확한2026년 내부 모습이 아니다. 시청 곡률·창 간격·포장폭·수정 빌딩의 세부 비례도 제작 가정으로 남긴다.
