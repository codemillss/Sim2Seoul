# L02 궁궐 외형 원천

`recipes.json`은 독립 제작한 절차형 메시의 색·비례·반복 간격이다. 공식 자료의 외형 특징은 L01 명세를 따르며 사진, 텍스처, 글씨 이미지, 외부 모델을 복제하지 않는다. 색과 수치는 실측이 아니다.

생성기는 `tools/prepare_palace_landmarks.py`다. 기존 지형과 L01 명세를 준비한 뒤 `.venv-data/bin/python tools/prepare_palace_landmarks.py`로 로컬 실행용 JSON과 해시 manifest를 만든다. `--check`는 두 파일을 재생성 값과 대조한다. 생성 파일은 Git에서 제외한다.

- 원본 footprint·구멍·미터 좌표와 현재 임시/성분 유래 높이 상한 안에서만 외형을 만든다.
- 원본의 긴 축을 절차형 외형의 가로축으로 쓴다. 대한문은 기존 통로에 수직인 축을 쓴다. 숫자 축과 전면 선택은 생성 결과에 남긴다. 사진에서 조사한 방향이 아니다.
- 다섯 닫힌 건물은 닫힌 면을 유지한다. 기둥과 창을 드러내는 0.2~0.32m 안쪽 외벽은 얕은 부조이며 들어가는 공간이 아니다. 대한문만 기존 3×3m 통로를 비운다.
- 낮고 굽은 지붕 면·기둥·색 띠로 한옥 전각을 단순화한다. 지붕 층수와 처마 구조의 분류를 혼동하지 않는다. 중화전은 현재 단층 외형이다.
- 석조전은 밝은 한 몸체·열주·박공·기단 띠로 만들며, 기존 본체와 별도 부재 전체를 중복해서 쌓지 않는다. 지층을 지상 세 번째 층으로 그리지 않는다.
- 돈덕전은 현존 재건 건물의 붉은 면·청록 창 두 줄·모서리 지붕을 단순화한다. 정관헌은 G03에서 선택한 이름 있는 footprint만 쓴다.
- 모든 새 노드는 표시 전용이다. 충돌·보행 권한·계단 접근·경로·지형을 추가하거나 변경하지 않는다.

모형의 인상은 구현 결과 화면에서 비교해야 하며 절차 생성 성공만으로 실제 건물의 정확도나 사용자 인지를 주장하지 않는다.
